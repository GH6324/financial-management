检测到 Docker 部署 · 用 sidecar(不在 app 容器内跑 OpenD)

app 跑在容器里,容器内既缺 gtk3、又是一容器一进程,不适合塞 OpenD。正确做法是把 OpenD 作为同网络的 sidecar 容器:

docker compose -f docker-compose.yml -f deploy/futu-opend.compose.yml up -d
  • · 富途无官方 OpenD 镜像 → 自备镜像写进 .env 的 FUTU_OPEND_IMAGE(记得把 gtk3 打进去),配 FUTU_ACCOUNT/FUTU_PWD_MD5。
  • · 起来后到「管理 → ⑥ 券商同步 → 富途」填 opend / 11111(compose 内服务名)。
  • · 详见 docs/broker-sync-guide.md 与 deploy/futu-opend.compose.yml 顶部说明。
