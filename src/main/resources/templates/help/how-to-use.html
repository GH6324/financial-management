主 教 程 · 01必修

建账户

先把家里的钱分门别类装进账户。账户是这个软件的基本单位 —— 之后所有的余额、收益、分析都挂在账户上。

9 类账户 账户 → 新建

现金 / 股票 / 理财 / 加密 / 贵金属 / 房产 / 贷款 / 保险 / 其他。有 16 个内置模板可以直接套(招行储蓄卡、余额宝、富途证券…), 套模板会帮你把平台、币种、产品类目一起填好。

每个账户填三件事 主理人 · 平台 · 币种

主理人决定「按成员看」时算谁的;平台决定「平台安全」视角; 币种支持 CNY / USD / HKD,系统自动换算。这三个现在随手填,后面分析时就有得切。

贷款账户 正负号系统自动处理

房贷、消费贷、信用卡都建成「贷款」类型,余额填还欠多少。填正数或负数都可以,系统会统一存成负债,不会算错。

主 教 程 · 02必修

每月填报

这个软件不用记流水。每月进填报页做三件事,顺序照下面来能少返工。

① 先录收入(逐笔) 填报 → 现金收入 / 股票收入

填金额 + 类目 + 这笔钱进了哪个账户。工资、奖金、股息、利息都这么记。 录一笔,系统会立即把钱加进那个账户的余额,还留下一条流水。收入笔数少,逐笔记得起来。

② 再填支出(一个总数) 填报 → 本月总支出

每位家庭成员各填一个数,从微信 / 支付宝 / 信用卡账单抄总数过来即可。不用拆分类、不用逐笔 —— 支出笔数太多,逐笔不现实,而这个软件分析的是余额变动,不是支出构成。

③ 最后核对余额 填报 → 各账户行

收入已经在第 ① 步自动进去了,这里通常只需确认。某个账户忘填也不会缺口 —— 系统会沿用上一期余额,但数就不准了。

跨账户搬钱要记一笔 填报 → 账户间划转

从工资卡转 5 万去证券账户,用「划转」记,系统知道那是搬家、不算收入也不算支出。 不记的话总净资产还是对的,但账户级收益率会失真(转出的看起来亏了 5 万)。

演 示 A

为什么必须「先录收入,后核余额」

关键机制:录一笔收入,系统会立刻把这笔钱加进那个账户的余额。 所以两种顺序的结果完全不同 —— 左边对,右边多算了一次。

① 先录收入 → ② 后核余额　（正确）
月初账户余额 ¥16,519
录入工资 +10,000 自动入账
账户余额变成 ¥26,519
核对月末余额:与银行 App 一致 无需改动
余额 ¥26,519 正确。收入既进了余额,也留下了一条流水 —— 之后「人赚 / 储蓄率」都算得对。
① 先填余额 → ② 再录收入　（会重复计）
月初账户余额 ¥16,519
直接填月末余额(已含工资) ¥26,519
又去录了那笔工资 +10,000 再次入账
账户余额变成 ¥36,519
凭空多了 ¥10,000。净资产虚高,而且这笔钱会被算成「人赚的」两次 —— 储蓄率、收益率跟着一起错。

主 教 程 · 03必修

关账

填报页会显示「家庭本月已填收支:N / M 人」和哪些账户还没填。都齐了就关账。

关账不是走形式 管理 → 周期管理

收益类指标(本月资产收益 / 家庭 XIRR / 资产年化 / 人赚钱赚)只统计已关账的账期。 因为填报中的月份通常是「余额填了、收支还没录齐」,拿它算收益会把没录的收支当成投资收益。 所以没关账 = 这个月不进收益统计,页面上会标明当前算的是哪一期。

主 教 程 · 04必修

看这个月发生了什么

仪表盘上由粗到细看四步,五分钟。

① 概览 仪表盘顶部

净资产多少、比上月涨跌多少、紧急储备够几个月、总资产总负债各多少。

② 人赚 vs 钱赚 仪表盘 · 本期怎么变

这个月资产变化里,多少是工资攒下来的(人赚),多少是投资赚的(钱赚)。等式:ΔNW = 人赚 + 钱赚 + 开账基线。

③ 归因复盘 仪表盘 · 归因复盘

变化具体由谁贡献。可切「账户 / 成员 / 平台 / 币种 / 账户类型」五个视角,还有 12 期趋势。

④ 资产洞察 仪表盘 · 洞察条

系统按规则自动给的提示:负债率偏高、应急金不足、过度集中、可考虑提前还贷等。

主 教 程 · 05必修

一条总原则

记住这句,九成「这笔钱要不要记」的问题自己就有答案。

不算收支

钱在你自己账户之间移动

转账、买基金、卖股票、还房贷本金 —— 你没变穷也没变富,只是钱换了个地方待着。只影响各账户余额。

算收支

钱真正进出你家

工资、奖金、吃饭、房租、利息 —— 收入逐笔录(选进账账户),支出填一个总数。

几个容易犹豫的场景
同一账户里买卖基金什么都不用做,月末余额自然反映
还房贷贷款余额减 + 现金减 · 利息自动体现
借钱给别人建「其他」账户记应收
股息 / 利息到账留在账户不用记 · 打进现金则录收入
补录一个已有钱的老账户直接建 · 自动识别为「开账基线」,不虚高收益

选 修 A让录入更省力

让录入更省力

持仓多、手输烦的时候再看。这几项都不影响记账正确性,只是省事。

A1 · AI 截图智能填报 填报 → 账户行「AI 截图导入」

基金/券商 App 里堆着十几支持仓、手 key 太累?截图上传,视觉大模型识别出每支的「名称 + 市值」并自动打标,和已有持仓做左旧右新三态比对(更新 / 新增 / 卖出),扫一眼确认即入库。只转写不算数,识别不准会诚实标疑。用你自己的通义千问 key,成本几毛/月。

A2 · 券商自动同步 账户 → 券商 / 填报页账户行「券商」

富途 / 老虎的只读同步:自动拉持仓与账户现金,不下单、不动钱。一个账房账户对应一个券商交易账户(1:1),有多个券商账户就各建一个。凭据在「数据源接入」里配。

A3 · 富途 OpenD 网关 管理 → 数据源接入 → 券商段

富途的同步要先在本机跑一个 OpenD 网关。向导里能下载、托管、自检,只绑 127.0.0.1、密码只存 MD5。配好后从持仓页的状态条能一眼看到「同步已启用 / 上次同步时间 / OpenD 地址」。

A4 · 逐笔持仓与自动估值 账户 → 持仓管理

填代码 + 份额,系统每天自动拉价估值,连月末余额都不用手填。股票支持美股 / A 股 / 港股(新浪主 + 腾讯备)。添加持仓时可勾「从账户现金划转买入」,自动扣掉「股数 × 成本」。

A5 · 贵金属与加密 持仓管理 → 添加持仓

贵金属按克 / 盎司录,金银铂钯走新浪 SGE 上海价或国际现货价;加密走 Binance 主源,CoinGecko / Coinbase 备源。

选 修 B看懂自己的钱

看懂自己的钱

攒够两三期数据后,这部分最有价值。

B1 · 资产打标 资产透视 → 资产打标

给每笔钱贴上风险 / 大类 / 行业 / 用途 / 地域等标签。不打标的资产在分析里会显示成一大块「未分类」,风险视图就失真了。支持 AI 推荐打标,一次批量处理。

B2 · 基金穿透 资产打标 → 穿透

公募基金拆成背后真实的「股 / 债 / 现金 + 申万行业」,行业维度出的是真实分布而不是一个「基金」单标签。只用公开代码查,金额不出服务器。理财类查不到的会诚实标「未穿透」。

B3 · 资产透视:从全貌钻到具体一笔 资产透视

10 个维度 × 7 个指标 × 10 块预设看板。四个组件分工不同,下面这个演示专门讲清楚它们怎么配合 —— 这是最多人卡住的地方。

这条路径最容易卡住的一点:明细抽屉只能从交叉透视的格子点开 —— 旭日负责缩小范围,透视负责定位,抽屉才落到具体持仓。很多人在旭日上反复点,以为哪里能看到明细。

B4 · 归因复盘 仪表盘 → 归因复盘

把这个月净资产的变化拆到各个贡献方,可切账户 / 成员 / 平台 / 币种 / 账户类型五个视角,并有 12 期趋势。它回答「变化从哪来」,和「人赚 vs 钱赚」回答的「变化是什么性质」互补。

B5 · 收益与基准 报表 → 收益概览 / 账户级收益 vs 基准

家庭 XIRR(含收入)是资金加权,把工资也当投入;资产年化 TWR(剔收入)剔除工资,纯看钱替你赚的。账户级那张表逐个账户对标其产品类目的长期基准,给出跑赢 / 跑输多少个百分点。不满 12 期时基准会按窗口折算再比,不会拿年化硬套三个月。

B6 · 财富水位 报表 → 财富水位

在净资产曲线上叠两条线:CPI 购买力线(你的钱还买得起当年同样的生活吗)和 M2 社会财富线(你在社会财富里的位置是升还是降)。名义涨 8% 但跑输 M2,意味着相对位置其实在退。

B7 · 储蓄能力 报表 → 储蓄能力

月均收入 / 月均支出 / 储蓄率 / 月储蓄能力(近 6 期中位数)/ 已填月份 N/12,外加近 12 期收支双柱图。没填的月份画灰柱且不参与中位数计算,免得空月份把结论带偏。

选 修 C规划与决策

规划与决策

C1 · 资产体检 资产体检

配置 / 风险 / 流动性 / 收益 四个维度的诊断,点账户列表行可下钻到单账户体检。可接 AI 出解读 —— 所有数字都是工程算好的,AI 只负责解释,不荐产品、不预测涨跌。

C2 · 配置对照与调仓建议 报表 → 资产配置对照 / 调仓建议

先在管理页设定各大类的目标占比(配置锚),报表里就会显示现状与目标的偏离。再往下是 AI 给的具体动作:「从 X 调 ¥N 到 Y」,可以采纳成计划并逐条核销。

C3 · 财务目标 目标

三个预设:FIRE 退休(通胀现值 + 4% 提取率,目标支出可自适应近月真实支出)、子女教育、应急储备;也可以自定义目标,挂在净投入 / 储蓄率 / 应急月数 / 资产年化等指标上。每个目标给三情景预测(乐观 / 中性 / 悲观)和进度落后判定。

C4 · 提前还贷决策器 报表 → 提前还贷

按 18 年 NPV 视角,把「提前还贷省下的利息」和「这笔钱拿去投资的预期收益」放在一起比,算该不该提前还。

选 修 D进阶与维护

进阶与维护

D1 · 多币种 管理 → 汇率维护 / 页面右上角币种切换

本位币定家庭主币,视图币种是显示镜头 —— 切币种时金额按汇率缩放,而比值类指标(收益率、储蓄率、紧急储备月数)三种币种下完全相等。汇率自动拉取,也可手工覆盖。

D2 · 指标设置与产品类目 管理 → 指标设置 / 产品类目

「指标设置」控制账户级表格显示哪些列(仪表盘与报表共用一套开关);「产品类目」定义每类产品的流动性、风险等级和长期基准% —— 紧急储备算不算它、体检怎么判风险、基准对标多少,都由这里决定。

D3 · 提醒、备份与审计 管理 → 提醒 / 备份与恢复 / 审计日志

截止前 N 天发短信提醒(阿里云,可选),站内 banner 兜底;备份可一键导出、也可从备份恢复,还能导出 CSV 账本;审计日志记录谁在什么时候改了什么。
