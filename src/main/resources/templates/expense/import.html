通道二 · 截图转写 还没做好

银行 App 大多没有 csv 导出,只能拍它的收支统计页。这条路我们还没接上 —— 统计页给的是算好的汇总数,而这一版导进来的是一笔一笔的流水,两者对不上。

眼下的办法:银行卡里走支付宝/微信的部分,导那两家就够了; 剩下的(房贷、代扣、线下刷卡)手工记几笔 —— 通常一个月就三五笔。

怎么把账单导出来
支付宝

我的 → 账单 → 右上「···」→ 开具交易流水证明 → 选「用于个人对账」→ 支付密码 → 时间范围最长可选 1 年,建议勾上「展示交易对手信息」「展示商品说明信息」(账单更全,归类更准)→ 填邮箱 → 提交。
解压密码在支付宝的「服务消息」里推送(「开具记录」里也能查)。

截图通道拍这一页:我的 → 账单 → 月账单
微信

我 → 服务 → 钱包(旧版是「我 → 支付 → 钱包」)→ 右上「账单」→ 等列表加载完 → 「常见问题」→ 下载账单 → 选「用于个人对账」→ 时间范围一次最多 3 个月(整年要分 4 次)→ 填邮箱 + 支付密码。
解压密码在「微信支付」的通知消息里 —— 先记密码再去邮箱。

截图通道拍这一页:钱包 → 账单 → 右上「统计」
银行(招商 / 工商等)

先走截图通道:招行 App 首页「收支明细 / 月账单 · 结余月历」自带场景分类,工行同理 —— 拍那一页即可。
文件解析暂时不接:各家银行导出的格式互不相同(招行 App 给的是 PDF,要 Excel 得走网银), 没有真实样本我们不写解析器 —— 写了大概率是错的。

别重复导:银行卡流水里必然包含走支付宝/微信的那些扣款。 已经导过这两家的话,银行侧只该补「不走它们的部分」(房贷、代扣、线下刷卡)。

账单是你整月的消费流水 —— 这是这个 app 接过的最敏感的东西。

  • 文件不落盘:解析完即弃,只留「每个类目多少钱」这几个数。
  • 金额永不发给 AI。支付宝账单全程不过 AI(它自带分类,确定性解析)。
  • 截图通道会把图发给你自己配的视觉服务 —— 用的是你自己的 key,和持仓截图导入同一条路。
  • zip 解压密码用完即弃,不入库、不进日志。
