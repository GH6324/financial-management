# LLM API Key 申请与配置指南

本文档面向**部署本应用的家庭管理员**(也就是你),用于配置 AI 能力(资产体检 / 月报 / 调仓建议 / 持仓截图识别)所需的 LLM API Key。

你**不需要改任何代码**,也不需要改服务器配置文件:去厂商那里申请 API Key,然后到管理页 `/admin/integrations` ① 段填进去即可(见第 3 节)。

> **v1.13 起改成三级模型**:平台(去哪家、用哪把 key)→ 模型系列(哪一族模型)→ 型号(具体发哪个 model)。
> 这三样以前是混在一个「供应商」字段里的,而火山方舟同时托管豆包**和** DeepSeek —— 不拆开就接不进来。

---

## 1. 需要准备什么

**一家都不配也能用**:AI 相关的四个功能会降级隐藏 / 显示规则引擎产出的原文,记账、净资产、真实年化、图表等**全部正常**。
配**一家**就能用;配两家可以在管理页设「备选」,主选故障时自动兜底。

| 项目 | 阿里云百炼(DashScope) | DeepSeek 官方 | 火山方舟(Volcengine Ark) |
|---|---|---|---|
| 厂商 | 阿里云 | 杭州深度求索 | 字节跳动 · 火山引擎 |
| 控制台 | bailian.console.aliyun.com | platform.deepseek.com | console.volcengine.com/ark |
| 需要的凭证 | **1 个 API Key**(`sk-` 开头) | **1 个 API Key**(`sk-` 开头) | **1 个 API Key** |
| 需要 AccessKey/Secret 配对吗 | **不需要**,OpenAI 兼容模式只认单 key,别去 RAM 控制台翻 AK/SK | **不需要** | **不需要**,方舟 API Key 与火山 AK/SK 是两码事 |
| 需要实名认证吗 | **需要**(支付宝/银行卡) | **需要**(手机号 + 实名) | **需要,而且是硬门槛** —— 没实名连 API Key 都建不出来 |
| 模型系列 | 通义千问 `qwen` · 通义千问 VL `qwen-vl`(视觉) | `deepseek` | 豆包 `doubao` · 方舟托管的 `deepseek` · 豆包视觉 `doubao-vision` |
| 有推荐型号可选吗 | **有**(`qwen-plus` / `qwen-flash` / `qwen-max`,可留空自动) | **有**(`deepseek-chat` / `deepseek-reasoner`) | **没有 · 型号必须手填**(见下方说明) |
| 支持截图识别(视觉) | **支持** | **不支持**(没有视觉模型) | **支持**(豆包视觉系列) |
| 免费额度 | 新用户 token 包,家庭场景基本用不完 | 无,按量计费(充 ¥10 够用好几年) | 新用户有免费 token,按模型给 |
| 预估月成本(家庭场景) | < ¥0.20(详见第 6 节) | 几乎为 0(只在主选挂掉时才走) | 同量级,取决于选的型号 |

> **为什么方舟的型号必须手填**:方舟的调用目标是你在控制台自己创建的**接入点(endpoint)**,ID 形如 `ep-20260214xxxxxx-xxxxx`,
> 每个账号都不一样;部分模型也支持直接填模型 ID。这类值**没有任何可以预置的固定清单**,所以管理页对方舟不提供推荐型号,
> 留空会**当面报错而不是静默回落** —— 静默回落到一个不存在的型号,只会让你在几天后才发现 AI 功能一直是坏的。

> **为什么主选默认建议 qwen-plus 而不是更便宜的档**:体检建议文案对**数字保真**要求极高(原文「应急储备 2.1 个月」绝不能被改写成「约 2 个月」)。
> 更小的模型在强约束 prompt + 数字逐字符保留任务上偶有失误。代价是单价高 3 倍左右,但家庭场景一年总成本仍 < ¥3。

## 2. 怎么获取(分步骤)

### 2.1 阿里云百炼 API Key(推荐首选 · 唯一一家「文本 + 视觉」都全的)

1. **注册阿里云账号**
   - 打开 <https://www.aliyun.com/>,右上角"注册"
   - 用手机号注册,绑定支付宝(必须)

2. **完成实名认证**
   - 进入 <https://account.console.aliyun.com/>(账号中心)
   - 左侧菜单找"实名认证",选"个人实名",用支付宝授权一键完成

3. **开通百炼大模型服务**
   - 打开 <https://bailian.console.aliyun.com/>
   - 首次进入会弹"开通服务"协议,勾选同意 → 开通(免费,只是开通,不扣钱)
   - 开通后会自动赠送新人 token 包

4. **创建 API Key**
   - 在百炼控制台,点击右上角头像旁边的钥匙图标,或直接打开 <https://bailian.console.aliyun.com/?tab=model#/api-key>
   - 页面顶部按钮"**创建我的 API-KEY**" → 选择业务空间(默认 default 即可) → 填描述比如"家庭资产管理 web app" → 创建
   - 弹窗显示完整的 `sk-xxxxxxxxxxxxxxxx`(**只显示一次**),立刻拷贝出来。如果忘记拷贝,只能再创建一个新的

5. **(可选)充值**
   - 7000 万免费 token 用完之前都不用充,家庭场景大概率永远用不完
   - 真要充的话:控制台右上角"费用"→"充值",最低 ¥10

### 2.2 DeepSeek 官方 API Key(可选 · 适合当备选)

1. **注册 DeepSeek 账号**
   - 打开 <https://platform.deepseek.com/>
   - 右上角"登录/注册",手机号验证码注册即可

2. **完成实名(如果系统要求)**
   - 个人 API 用户一般不需要单独实名,手机号即视为实名
   - 如果触发风控要求补充身份证,按页面引导走支付宝授权即可

3. **充值**
   - 进入 <https://platform.deepseek.com/top_up> 或左侧菜单"充值"
   - 支持微信/支付宝,最低 ¥1。**建议直接充 ¥10**,够这个 app 跑好几年

4. **创建 API Key**
   - 打开 <https://platform.deepseek.com/api_keys>
   - 点页面中央"**创建 API Key**" 按钮 → 给个名字比如 `finance-app-fallback` → 创建
   - 弹窗显示完整的 `sk-xxxxxxxxxxxxxxxx`(**只显示一次**),立刻拷贝。失误只能重新建

### 2.3 火山方舟 API Key(可选 · 想用豆包 / 方舟托管的 DeepSeek 就配它)

1. **注册火山引擎账号**
   - 打开 <https://www.volcengine.com/>,手机号注册

2. **完成实名认证(这一步绕不过去)**
   - 进入账号中心 → 实名认证,个人可用支付宝授权
   - **没实名的账号在方舟控制台建不出 API Key**,也调不了模型。如果你在第 3 步找不到创建按钮,先回来看这一步

3. **开通方舟 + 开通要用的模型**
   - 打开 <https://console.volcengine.com/ark>
   - 左侧「开通管理」里,把你要用的模型逐个开通(豆包文本 / 豆包视觉 / DeepSeek 各自独立开通)
   - **只创建了 key、没开通模型 → 调用会报「该型号未在控制台开通」**

4. **创建接入点,拿到型号 ID**
   - 左侧「在线推理」→ 创建接入点,选好模型 → 创建后会得到一个 `ep-` 开头的**接入点 ID**
   - **把这个 ID 复制下来**,它就是管理页里要填的「型号」。部分模型也可以直接填模型 ID,以控制台显示为准

5. **创建 API Key**
   - 左侧「API Key 管理」→ 创建 → 复制保存(只显示一次)

6. **想用方舟做截图识别的话**
   - 模型系列选「豆包视觉」,型号填你**为视觉模型创建的那个接入点 ID**
   - 文本接入点和视觉接入点是两个不同的 `ep-`,别混用 —— 拿文本接入点发图片会直接报错

## 3. 配置方式

**都在管理页里配,不用碰服务器配置文件。**

1. 用管理员登录,进 **管理 → 数据源接入**(`/admin/integrations`),第 ① 段就是「AI 大模型」。
2. **粘密钥**:三张卡各对应一个平台,填对应的 API Key。**留空 = 保持原值**(不会被清掉),已配的显示「已配置(隐藏)」,任何时候都不会明文回显。
3. **选模型**:主选 / 备选 / 截图识别各是一组「平台 → 模型系列 → 型号」。
   - 型号留空 = 用该系列的推荐型号;
   - **火山方舟必须手填型号**(控制台复制的 `ep-` 接入点 ID 或模型 ID),留空会当面报错;
   - 备选平台选「不设备选」= 不做兜底,主选失败就如实报错。
4. **截图识别**是独立开关,关掉之后持仓截图导入入口会隐藏,其余 AI 功能不受影响。
5. 每张卡下面有「**测试连接**」:用**已保存**的密钥 + 当前选中的型号发一次最小探测,失败会直接告诉你是 key 不对、型号不存在、还是没开通/没实名。
   - 注意:测试用的是**已保存**的配置,所以改完记得先点「保存 LLM 配置」再测。

改完点保存即时生效,**不用重启服务**(超时秒数除外)。

### 首次部署时的可选 seed

只在**全新安装**时,`deploy/deploy.sh` 会把 `/etc/finance.env` 里的这三个变量一次性灌进数据库,方便无人值守装机:

```
FINANCE_LLM_QWEN_API_KEY=
FINANCE_LLM_DEEPSEEK_API_KEY=
FINANCE_LLM_ARK_API_KEY=
```

这一步是**幂等且只跑一次**的(打了标记文件),之后一切以管理页为准 —— 你在管理页改过的值不会被后续部署覆盖回去。
文件权限记得收紧:`sudo chown root:finance /etc/finance.env && sudo chmod 640 /etc/finance.env`。

## 4. 建议

- **配一家就够**。哪一家都行,按你已有的账号来:已经有阿里云 → 配百炼(顺带把截图识别也解决了);已经用豆包 → 配方舟。
- **备选是可选的**。设了备选,主选超时/限流/欠费时会自动换第二家再试一次;不设就只试一次,失败如实报错。
- **一家都不配也 OK**。AI 体检 / 月报 / 调仓建议 / 截图识别会降级(体检显示规则引擎产出的原文,截图导入入口隐藏),其余功能全部正常。
- **截图识别不做主备兜底**。它发生在你等结果的路上(传图 → 等),失败再换一家会把最坏等待翻倍,所以只有一组配置,失败就报错让你重试。
- **不要把 key 提交到 git**。key 存在数据库里(私密字段),不入仓库、不进日志、不进操作记录。**永远不要**把 key 写进 `application.yml` 或代码。

## 5. 隐私边界

为保护家庭隐私,本应用对送给 LLM 的内容做了严格的**脱敏白名单**:

### 会送给 LLM 的字段(都是结构化代号 / 数字,不含个人信息)

- 资产**类目代号**(如 `CASH_DEPOSIT`、`STOCK_A`、`BOND_GOV`、`REIT`、`INSURANCE_LIFE`)
- 资产**风险等级**(如 `R1` ~ `R5`)
- **金额数字**(¥150,000 这种纯数字)
- **占比数字**(如 "现金占比 35%")
- **规则代号**(如 `CASH_RATIO_TOO_HIGH`、`EQUITY_OVERWEIGHT`)
- 总资产数字、家庭成员**数量**(数字,不是名字)

### **绝不**送给 LLM 的字段(全部脱敏在本地)

- ❌ **账户名 / 银行名 / 券商名**(如 "招商银行卡尾号 8721"、"老婆的华夏基金账户")
- ❌ **用户名 / 真实姓名 / 微信昵称**
- ❌ **账户备注 / 自定义标签 / 操作记录**
- ❌ **家庭名 / 家庭成员姓名 / 关系标签**(如 "爸爸"、"老婆")
- ❌ **任何身份证号 / 手机号 / 邮箱 / 地址**
- ❌ **历史明细 / 流水**(只送当前快照的聚合占比,不送时间序列)

技术上这个边界由后端的 `LlmPromptBuilder` 强制实现,前端页面不参与;送给 Qwen / DeepSeek 的 prompt 内容你可以在 `journalctl -u finance` 日志(DEBUG 级别)中审计。

## 6. 成本估算

### Qwen-Plus 当前定价(2026-05 阿里云百炼)

- **输入**: ¥0.0008 / 千 tokens
- **输出**: ¥0.002 / 千 tokens
- **新人免费额度**: 7000 万 tokens / 90 天(turbo + plus 共享额度)

### 单次调用规模

一次"资产体检"单条建议润色,典型 token 用量:

- 输入(system prompt + 1 条 advice 原文 + 数字保真约束):约 **400 tokens**
- 输出(润色后的单条建议,80-120 字):约 **150 tokens**
- **单次成本**: 400 × 0.0008/1000 + 150 × 0.002/1000 = **¥0.00062**(约 0.06 分)

### 月度 / 年度估算

- 家庭场景使用频率:每月录入/调整资产约 5-10 次,每次触发 1-2 次体检,每次体检最多润色 5 条建议
- **月调用次数**: 约 20-50 次
- **月成本**: 50 × ¥0.00062 ≈ **¥0.031**(三分钱)
- **年成本**: ≈ **¥0.37**
- 7000 万免费 token 大约够跑 **12 万次单条建议润色**,等于免费用很久

### DeepSeek-Chat 定价(仅 fallback 触发时)

- 当前(2026-05)有效价: **¥2 / 百万 tokens 输入**, **¥8 / 百万 tokens 输出**(即 ¥0.002/千 输入, ¥0.008/千 输出)
- 仅在 Qwen 挂掉时触发,家庭场景一年加起来可能就几次,可以忽略不计

**结论:全年总开销 < ¥3**。即使最坏情况(Qwen 免费额度用完 + 频繁触发 fallback + 用户狂刷体检),也撑死不超过 ¥10 / 年。

## 附录:故障排查

| 现象 | 可能原因 | 怎么查 |
|---|---|---|
| 体检建议是"机械模板句" | 一家 key 都没配 / 都失效 | 管理页 ① 段点「测试连接」,看具体报什么 |
| 保存时报「必须手工填写型号」 | 方舟没填型号 | 去方舟控制台「在线推理」复制 `ep-` 接入点 ID 填进去 |
| 测试连接报「型号或接入点不存在」 | 方舟型号填错 / 用了别的账号的接入点 | 接入点 ID 是账号维度的,只能从**你自己**的控制台复制 |
| 测试连接报「该型号未在控制台开通」 | 只建了 key,没在「开通管理」里开通模型 | 回方舟控制台逐个开通要用的模型 |
| 测试连接报「账号未完成实名认证」 | 方舟硬门槛 | 火山引擎账号中心做实名,再回来重试 |
| 测试连接报「Key 未配置」 | 密钥框留空(留空 = 保持原值,新装即为空) | 粘贴 key → **先保存** → 再测试 |
| 测试连接报 401/403 | key 拷错 / 首尾多了空格 | 重新创建一个,粘贴时注意空白字符 |
| 测试连接报「调用过于频繁」/「免费额度已用尽」 | 限流或额度耗尽 | 等一会再试,或换个型号/平台;设了备选的话正式调用会自动兜底 |
| 截图导入入口不见了 | 截图识别开关关着,或该平台 key 没配 / 型号没填 | 管理页 ① 段「截图识别」勾上,并确认平台 key + 型号都齐 |
| 体检页面卡住转圈很久 | LLM 超时 | 管理页把「超时秒」调小(改动需重启),或换更快的型号 |

服务端日志:`sudo journalctl -u finance -g "LLM"`(密钥不会出现在日志里,只有平台/系列/型号和失败原因)。
