# PRD · v0.13 · 新账户「开账基线」不计入当期收益(修投资收益虚高)

> 状态:**待评审(PRD + preview 阶段)** · 对应 preview `preview/v0.13/opening-baseline.html`
> 定位红线([[project_finance]]):账户级 · 10 分钟/月 · 不改净资产恒等式的资产口径,只修"收益归因"。

## 背景 / 要解决什么

用户在 beta 新建了一个加密货币账户、录了 1 枚 BTC(≈¥426,372)。现象:
- **净资产/总资产正确增加了**(资产是真的,应该计入)✓
- **但 dashboard「本期怎么变的」把这 ¥426,372 算进了「钱赚(投资损益)」**、「本月资产收益 +6.33%」也含它 → **投资收益虚高**。

**根因**:系统按 `钱赚 = ΔNW − 人赚(净流入)`、`本月资产收益 = 期末 − 期初 − 净流入` 归因。新账户**上一期不存在**(期初不含它)、又没被记成任何"收入/划转"→ 这笔**你本来就持有、这月才开始记录的存量本金**,被当成了"这个月投资赚的"。

**这不是 crypto 专属**:任何**中途新增一个已有余额的账户**(新开一张存了 ¥100k 的银行卡、补录一套房产、新券商账户…)都会把存量误算进当期收益。是 v0.12「收入=外部流入不进 PnL」同一类病的另一个触发点。

## 核心概念:开账基线(opening baseline)

> **开账基线** = 一个账户**首次被纳入记录的那一期**的期末净值(本位币;资产为正、负债为负)。
> 它是"你本来就有/欠的、现在才开始记"的**存量本金**,属于**外部资本纳入**,**既不是"人赚"、也不是"钱赚"**。

**恒等式从两项扩到三项**:
```
本期净资产变化 ΔNW = 人赚(净流入) + 钱赚(投资损益) + 开账基线(本期新纳入本金)
```
净资产/总资产**照常包含**开账基线(资产是真的);只是**所有"投资收益"类指标把它剔除**,不虚高。

## 功能需求(FR)

### FR-170 · 开账基线自动识别(零操作)
- 系统自动识别"**本期首次出现**的账户"(该期有余额、且此前任何一期都没有余额记录)。其当期期末净值(本位币)= 该账户的开账基线。全期合计 = 本期开账基线。
- **无需用户额外操作/勾选**:新建账户 + 录首个余额/持仓即自动生效(存量资产 = 首期基线)。

### FR-171 · 「本期怎么变的」卡拆出第三项 · 钱赚剔除开账基线
- 卡片在有开账基线的账期,**新增一行「新纳入本金(开账)」**,与「人赚」「钱赚」并列,三者相加 = ΔNW(卡内自洽)。
- **钱赚(投资损益)= ΔNW − 人赚 − 开账基线**(不再把新纳入的存量算成投资赚的)。
- 无新增账户的账期:该行为 0 / 不显示,卡片与现状一致。
- 一句话说明(给非技术家庭成员):「新纳入本金 = 你本来就有、这月刚开始记的钱,不算这月赚/赔的」。

### FR-172 · 「本月资产收益」剔除开账基线
- `本月资产收益 = (期末 − 期初 − 净流入 − 开账基线) ÷ 期初`,与钱赚同口径,不虚高。

### FR-173 · 家庭 XIRR / 资产 TWR 把开账基线当"外部资本流入"
- 真实年化(家庭 XIRR)、资产 TWR 把开账基线视为**当期外部资本注入**(像本金转入),从收益里剔除 → 年化不因"补录存量账户"跳升。

### FR-174 · 净资产/资产口径不变 · 币种/移动端一致
- 净资产、总资产、配置环、财富水位**照常包含**新账户(资产是真实的),不受本次影响。
- 开账基线走本位币口径,三视图币种比值不变([[feedback_currency_invariance]]);移动端卡片第三项同样展示。

### FR-175 · 只影响"新纳入当期" · 不追溯改历史
- 只在账户**首次出现的那一期**把它当基线;从**下一期起**该账户的余额变化正常计入人赚/钱赚。已关账的历史账期不追溯重算。

## 约束 / 非目标
- ❌ 不改净资产恒等式的**资产口径**(资产照常计入),只改"收益归因"的拆分。
- ❌ 不做逐账户/逐笔"这算不算我的收益"的人工开关(首期一律基线,自动);后续如需再议。
- ❌ 不处理"账户中途归档后又恢复"这类罕见断档(按"曾出现过即非新账户"处理,见 tech-design)。
- ❌ 不改 v0.12 收入侧 / 持仓估值本身。

## 验收标准
1. 新建一个账户并录入余额/持仓(如 crypto BTC ¥426,372):**净资产/总资产 +426,372**(照常),但 dashboard**「钱赚」不因这笔跳升**、「本月资产收益 %」不虚高。
2. 「本期怎么变的」卡显示三行:人赚 / 钱赚 / **新纳入本金(开账)**,三者和 = ΔNW;新纳入那行 = ¥426,372。
3. 家庭 XIRR / TWR 不因补录存量账户而跳升。
4. 无新增账户的账期:卡片、钱赚、收益率与现状**完全一致**(该项为 0)。
5. 三视图币种下比值不变;移动端第三项正常显示;已关账历史不变。
