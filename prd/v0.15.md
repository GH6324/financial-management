# PRD · v0.15 · 券商自动同步(富途 Futu / 老虎 Tiger · 只读拉持仓+现金)

> 状态:**待评审(PRD + preview 阶段)** · 对应 preview `preview/v0.15/broker-link.html`
> 定位红线([[project_finance]]):账户级 · 10 分钟/月 · 非技术家属看得懂 · 自托管数据只在自己服务器。
> **重定位声明**:本版**突破**原「不做券商 API 直连」非目标 —— 但严格限定为 **只读**(拉持仓 + 现金),**永不下单**。目的:港美券商账户免手填,省下每月抄总数的功夫。

## 背景 / 要解决什么
用户资产分散在支付宝 / 招行 / 东财 / 富途 / 老虎等多个 App,每月手填麻烦。调研结论([[reference_headless_screenshot]] 之外的 API 调研):
- **富途、老虎有官方个人 OpenAPI**,能只读拉自有**持仓 + 现金**,合规、可行 → 本版做。
- 大陆支付宝/招行/东财**无面向个人的只读第三方授权**(东财只发"交易密码/全权 ticket",无只读 scope)→ 本版**不做**,留作后续「对账单导入」另议。

## FR-A · 券商账户 → 「账房」账户 的映射
券商侧真实结构 → 我们抽象模型,**一一对应、复用现有持仓/估值链**(与 AUTO/CASH 持仓模型天然契合):

| 券商侧 | 账房侧 | 说明 |
|---|---|---|
| 一个**交易账户**(富途 acc_id / 老虎 account · 真实账户) | **一个 Account**(type=STOCK) | 1:1;displayName 默认「富途证券」/「老虎证券」可改;**币种以用户建账户时选的为准**,底层各币种 FX 折算过来(FR-A 币种口径) |
| 每一笔**股票持仓**(HK.00700 / US.AAPL / SH.600519 …) | 一条 **AUTO `stock_holding`** | ticker + market + shares + cost_basis + currency;打上 `sync_source=FUTU/TIGER` 标记 |
| 各币种**现金**(HKD / USD …) | 每币种一条 **CASH `stock_holding`** | 复用现有多币种现金 + FX 折算 |
| **期权 / 期货 / 债券** 持仓 | **不同步(v1 非目标)** | 我们模型无期权;同步时**跳过并提示**"另有 N 笔期权/期货未纳入,请手动补" |

- **市场/代码归一**:富途 `HK./US./SH./SZ.` 前缀、老虎 symbol+market → 我们的 `Market`(US/CN/HK)+ 纯 ticker。加密不经这两家,不涉及。
- **估值**:同步来的 AUTO 持仓仍走**现有价格引擎**(新浪/腾讯拉价)估值,与手填持仓同源一致;券商返回的现价作为**兜底/回填**(离市时对齐券商)。**成本价(cost_basis)取券商**,用于盈亏。
- 多账户:若用户在券商下有多个交易账户,可各自关联到一个账房账户(1:1)。

## FR-B · 关联交互(两种入口)
### FR-B1 · 新建账户时关联(create + link)
- 账户新建向导里,STOCK 类型下多一个选项:**「券商自动同步(可选)」→ 富途 / 老虎**。
- 选中后:账户以 STOCK 建好并标记 `linked_broker=FUTU/TIGER` + 券商账户号 → **立即首次同步** → 持仓/现金自动灌入。
- 未配置该券商凭据时,引导去「管理 → 数据源接入 → 券商同步」先配(见 FR-D)。

### FR-B2 · 已有账户关联(link existing · 高危二次确认)
- 在已有 STOCK 账户的持仓页 / 详情页:「关联券商自动同步」→ 选券商 + 选券商账户(多账户时列出)。
- **二次弹窗确认(强制)**:关联接管是**高危、不可自动回退**操作 → 弹窗明示「关联后由券商同步接管,现有手填持仓将被归档;此操作不可自动撤销,但已为你留存关联前快照」,用户须**勾选「我已知晓」+ 再次点确认(两步)** 才执行。
- **策略 = 替换**:关联时归档该账户现有的手填 / 非同步持仓,改由 `sync_source` 同步持仓承接(避免同一持仓两份 → 重复计值)。
- 关联后账户标「券商托管」;可**随时解绑**(解绑后同步来的持仓保留为普通持仓,可手动维护;被归档的旧持仓按 FR-B3 找回)。

### FR-B3 · 关联快照 · 可技术找回(不可回退操作的兜底)
关联(替换)前,对将被接管/归档的持仓**落双份快照**,后悔了能技术找回:
- **软归档**:被替换的持仓一律 `archived_at` 软删(**绝不物理删除**),可 restore 复原。
- **审计快照**:写一条 `audit_log`(类型 `LINK_BROKER`),body 存关联前持仓 JSON 明细(账户 / ticker / shares / 成本 / 币种 / 手填市值),持久留痕。
- 找回路径:「解绑 + 恢复归档持仓」;或运维按审计快照人工还原。弹窗文案明确告知快照已留存。

## FR-C · 同步逻辑(reconcile)
- **触发**(手动 + 定时都要):①关联时首次同步 ②持仓页 / 填报页「同步券商」按钮(手动)③**cron 定时**(数据源接入页配,与股票拉价同页)。
- **对账(reconcile)**,只动 `sync_source` 标记的行,**不碰用户手填持仓**:
  - 券商有、我方无 → 新建 AUTO 持仓。
  - 两边都有 → 更新 shares / cost_basis。
  - 我方有(synced)、券商已无 → **归档**(已卖出)。
  - 现金按币种 upsert CASH 行。
- 同步后触发既有估值刷新 → 写回账户余额/快照。

## FR-D · 凭据与安全(只读红线)
- 凭据走**管理页 → 数据源接入 → 「券商同步」新段**([[feedback_admin_runtime_config]]),私密存 `family_runtime_config`(加密),不回显、不入 audit 明文([[feedback_prod_backward_compat]] 同款私密纪律)。
- **富途**:配 `FutuOpenD` 连接(host:port)+ 选账户;**只调查询接口、永不 `unlock_trade`** → 不存交易密码、物理上不能下单。需运行 OpenD 网关(部署现实见评审点)。
- **老虎**:配 `tiger_id` + RSA 私钥;**只调 `get_assets`/`get_positions`,永不下单**;key 加密存、可吊销;文案明确告知"key 可交易,请视为高敏感"。
- 一键「测试连接」(同 LLM 段范式):验证能拉到账户信息,不做任何写操作。

## 非目标(v1)
- **不下单、不改单、不转账** —— 纯只读。
- 不同步期权 / 期货 / 债券(只股票 + 现金);不做大陆(支付宝/招行/东财)API。二者均记入 [`docs/backlog.md`](../docs/backlog.md) 待后续排期。
- 不做逐笔成交流水导入(只月度快照需要的"持仓 + 现金"状态)。
- 不替用户保管富途登录态的自动续期(OpenD 掉线需用户重登,见评审点)。

## 验收标准
1. 管理页配好老虎 key → 新建账户选「老虎自动同步」→ 持仓 + 各币种现金自动灌入,估值并入净资产;点「同步」后与券商一致。
2. 已有手填 STOCK 账户关联富途 → 按所选策略(替换/并存)处理旧持仓,同步来的持仓带 `sync_source=FUTU`。
3. 券商卖出某票后再同步 → 该持仓自动归档、余额下降。
4. 期权/期货持仓被跳过并有提示。
5. 全程无任何下单能力;解绑后持仓保留可手动维护;三视图币种比值不变([[feedback_currency_invariance]])。

## 评审结论(已定 · 2026-07-09)
1. **富途优先** —— 先做富途(含 OpenD 网关接入),顺带做老虎;两家同版交付。✓
2. 已有账户关联 = **二次弹窗确认**:明确声明「高危 · 不可自动回退」,用户须显式确认;且见 **FR-B3 关联快照**——关联前对被接管持仓落一份可恢复快照/日志。✓
3. 同步节奏:**手动 + cron 都要**(手动同步按钮 + 定时任务,cron 在数据源接入页配)。✓
4. 期权 / 期货 **本期不做**,记入 [`docs/backlog.md`](../docs/backlog.md);同步时跳过 + 提示。✓
5. 关联账户币种 = **以用户在账房建账户时选的币种为准**;券商底层各币种持仓/现金一律 FX 折算到账户币种(再到本位币)。**理由**:用户建账户时选的币种就是他期望看到的镜头,不因底层是港币/美元而改。✓
6. **只读铁律**:绝不申请、绝不调用任何写 / 交易类 API。富途永不 `unlock_trade`;老虎只调 `get_assets`/`get_positions` 等查询;凭据文案要求用户尽量用最小权限,并声明"我们永不下单"。✓

## 迭代补记 · v0.15.x(beta 验收反馈)

1. **建证券账户时给同步提示**(FR-B1 补强):新建账户向导选「证券(STOCK)」时,浮出券商自动同步提示,告诉用户创建后可在持仓页开启。
2. **二次确认改自建弹窗**(FR-B2 补强):高危关联/解绑的二次确认不用系统 `confirm()`,改晚清账册风自建模态框(ESC/遮罩关闭)。理由:系统弹窗丑且不可定制,与产品一致性冲突。
3. **凭据获取图文向导**(新增 FR-E · 易用性):用户反馈「只读铁律」一句话没法照着配。新增应用内 `/help/broker-sync` 图文向导(富途/老虎分步 + 示意图 + 官方链接 + 字段映射)+ 仓库 [`docs/broker-sync-guide.md`](../docs/broker-sync-guide.md);管理页 ⑥ 段与关联页各挂入口。**理由**:券商 OpenAPI 面向开发者,非技术家人无从下手,必须手把手教到「填哪个框」。
4. **关联颗粒度重构**(FR-F · 用户 6 点评审,tech-design 决策 M):连接配置下沉到「关联」(V40:每关联可专属 OpenD host/port,多富途账号=多 OpenD);入口从持仓页迁到**账户页**(操作列「券商」+「券商托管」徽章);测试连接下沉到关联页并改**富卡片**(市场徽章/户号尾4/账户类型/持仓笔数/各币现金);OpenD 向导重构为**常驻黑色终端**(状态+日志+内嵌验证码,SSH 质感)+ 安装三形式 radio 级联;同步持仓用**券商证券名**做显示名(腾讯控股/小米集团-W,不再裸代码)。映射事实:一个富途账号 ≈ 一个综合证券账户(港美同户)↔ 我们一个账户。
