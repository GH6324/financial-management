# v1.7 · 交互式使用手册(PRD)

> 起因:issue #9 一位用户自述「没有相关背景」,问「理财的买入卖出、借钱等如何在这些体现,还是有些不好理解」。
> 查证属实 —— 此前站内帮助只有券商同步一篇,`docs/faq.md` 四章全是部署 / 备份 / 登录 / AI 这类**运维**问题,
> **一条「业务上该怎么记」都没有**。等于把门槛原封不动留给了没有财会背景的人。
>
> v1.6.32 先做了文字版与首版页面;本版把它升为**独立的交互式教程站内页**,故单开大版本。

## 1 · 为什么单开一个大版本

这不是"加一个帮助页",而是补上产品缺失的一整层:**教用户怎么用**。

- 覆盖面从「我想到的几件事」变成**功能全集**:70+ 路由 + 管理页 15 块 → 33 个功能点
- 组织方式从「按页面罗列」变成**按学习路径**:必修 8 + 选修 25,主教程 5 章 + 选修 19 节
- 表现形式从「文档」变成**教程**:每章可点进真实页面、每章配图、两处可交互演示

## 2 · 功能全集与必修 / 选修分类

| 分类 | 节数 | 内容 |
|---|---|---|
| **必修 · 主教程** | 5 | 建账户 → 每月填报 → 关账 → 看结果 → 一条总原则 |

## 3 · 功能需求

### FR-250 · 每章必须能点进真实页面

每一节标题旁给出**该功能的真实入口链接**(如「建账户」→ `/accounts`、「财务目标」→ `/goals`、
「提前还贷」→ `/reports/refinance`)。教程读到哪就能立刻去做,不用自己找路。
链接一律用 `th:href="@{...}"`,不写死路径。

### FR-251 · 每章图文并茂

每节配一张该功能的真实界面图(beta 实拍 · 隐私模式 · 统一套外框),
概念类章节改用内联 SVG 图解。两处**可交互演示**保留并作为示范:

| 演示 | 解释什么 |
|---|---|
| 填报顺序 | 录一笔收入会立即加进账户余额 → 顺序反了会重复计(左右对照,错误侧滚到 ¥36,519 变红) |
| 下钻三步 | 明细抽屉只能从交叉透视的格子点开(旭日缩范围 → 透视定位 → 抽屉落到单笔) |

### FR-252 · 教程页的表现形式可以比功能页更外放

它不是日常高频页面,而是**读物**。允许比功能页更大的标题、更强的装饰、章节编号、
滚动进场与悬停反馈 —— 但仍在现有设计令牌内(纸感底 / Fraunces 大标 / 等宽数字 / 黄铜森绿铁锈三色),
不引入新色系、不加载外部字体、不用 emoji(一律 inline SVG)。

### FR-253 · 新手醒目、老手不打扰

- **醒目**:仪表盘 + 填报页顶部引导卡,`localStorage.manualHintDismissedAt` 一年
- **常驻**:导航栏最末「手册」(PC 主栏 + 移动抽屉)+ 填报页标题旁「怎么填?」
- 导航栏 8 项**全部**配 icon —— 只有一项有 icon 是最难看的状态

## 4 · 非目标

- 不做交互式 checklist / 学习进度记录(不值得为教程页引数据表)
- 不做视频
- 不翻译成英文

## 5 · 二轮补强(用户第 27 轮反馈)

### FR-254 · 手册免登录

潜在用户在决定「要不要自己部署一套」之前,就该能读懂它怎么用。`/help/how-to-use` 放行匿名访问,
匿名态显示轻头(项目首页 / 登录),登录态显示完整导航。其余页面照旧要登录。

### FR-255 · 交互演示优先于截图

用户反馈:自建的下钻演示效果比截图好。故把交互演示从 2 个扩到 **4 个**:

| 演示 | 挂在 | 解释什么 |
|---|---|---|
| A · 填报顺序 | 主教程 02 | 录一笔收入会立即加进余额 → 顺序反了会重复计 |
| B · 下钻三步 | 选修 B3 | 明细抽屉只能从交叉透视的格子点开 |
| **C · 币种是显示镜头** | 选修 D1 | 点 CNY/USD/HKD:金额按汇率缩放,而比值四项**一个数字都不动** |
| **D · 人赚 vs 钱赚** | 主教程 04 | 三种情形切换,含「净资产涨 10 万、其实投资亏 6 万」 |

### FR-256 · 演示必须与真实界面高度一致

演示 A 重做成**仿真填报页**:控件、标签、配色照真实页面 1:1(「收入」绿标签、现金收入 / 股票收入、
金额 / 类目 / 现金账户、「+ 加一笔」黑按钮、「本期余额」输入框)。
**理由**:教程里学会了、到真实系统 UI 差异太大,等于没学会。

### FR-257 · 复杂章节一律图文并茂

补拍 数据源接入 / 富途 OpenD 向导 / 新建目标 / 指标设置 / 产品类目 / 备份 / 审计 共 7 张,
配图 15 → **21 张**。判据:除非文字三两句能说清,否则必须配图或配演示。
富途 OpenD 这类多步骤场景另指向站内既有的 `/help/broker-sync` 逐步图文向导。

### FR-258 · beta 截图不打码

beta 非真实数据,故关闭隐私模式重拍(`SHOT_PRIVACY=0`),金额直接可读 —— 打码反而让教学图看不清。

### FR-259 · 「进阶与维护」章节补厚

原来 3 条课节、2 张图,且汇率页配图是 300 行重复的 `CNY USD 0.148120`,没有教学价值。
现在:课节 **11 条**、配图 **5 张**、汇率图裁到顶部一屏,并把演示 C 挂在多币种章。
产品类目那节讲清了它决定什么 —— 流动性影响紧急储备分子、风险等级影响透视与体检、基准%影响 vs 基准。

### FR-260 · 手册要在公开落地页体现

手册免登录这件事,改变了落地页的转化逻辑 —— **以前访客只能「信」文案,现在能「自己验」**。
所以不是加个链接,而是给一条与「直接装」并列的路径。三处各干不同的活:

| 位置 | 做什么 | 为什么 |
|---|---|---|
| **hero** | 命令块下面「还没决定要不要装?」分隔 + 手册卡(标「不用装 · 不用登录」) | 没人会为一个还不确定适不适合自己的东西先装一套环境 |
| **中段五问** | 3 个问题挂手册章节锚点(`#b6` 财富水位 / `#ch4` 人赚vs钱赚 / `#b3` 钻到具体持仓) | 问题本来就写好了,只是**此前没有出口** —— 读者点头认同完就没下一步 |
| **footer CTA** | 加第三个按钮「先看使用手册」 | 给还没决定的人一个出口 |

**布局注意**:hero 那两块**不能左右并排** —— 命令块里 `git clone https://github.com/...` 那行 URL
不可断行,并排时会把手册卡挤成 88px 宽的细条(实测)。改上下堆叠后 PC 600×106 / 移动 345×129 正常。

> 顺带修掉一条长期失效的守护:`v09-LAND-5` 一直断言落地页命令块含 `docker compose up -d`,
> 但安装入口收敛那版起落地页给的就是 `bash deploy/docker-up.sh`(它内部才去调 compose)。
> 这条守护自那以后一直是红的 —— **断言的是已被淘汰的命令,等于长期失效**。已改成现口径。
