# v1.7 · 交互式使用手册(PRD)

> 起因:issue #9 一位用户自述「没有相关背景」,问「理财的买入卖出、借钱等如何在这些体现,还是有些不好理解」。
> 查证属实 —— 此前站内帮助只有券商同步一篇,`docs/faq.md` 四章全是部署 / 备份 / 登录 / AI 这类**运维**问题,
> **一条「业务上该怎么记」都没有**。等于把门槛原封不动留给了没有财会背景的人。
>
> v1.6.32 先做了文字版与首版页面;本版把它升为**独立的交互式教程站内页**,故单开大版本。

## 1 · 为什么单开一个大版本

这不是"加一个帮助页",而是补上产品缺失的一整层:**教用户怎么用**。

- 覆盖面从「我想到的几件事」变成**功能全集**:70+ 路由 + 管理页 15 块 → 33 个功能点
- 组织方式从「按页面罗列」变成**按学习路径**:必修 8 + 选修 25,主教程 5 章 + 选修 19 节
- 表现形式从「文档」变成**教程**:每章可点进真实页面、每章配图、两处可交互演示

## 3 · 功能需求

### FR-250 · 每章必须能点进真实页面

每一节标题旁给出**该功能的真实入口链接**(如「建账户」→ `/accounts`、「财务目标」→ `/goals`、
「提前还贷」→ `/reports/refinance`)。教程读到哪就能立刻去做,不用自己找路。
链接一律用 `th:href="@{...}"`,不写死路径。

### FR-251 · 每章图文并茂

每节配一张该功能的真实界面图(beta 实拍 · 隐私模式 · 统一套外框),
概念类章节改用内联 SVG 图解。两处**可交互演示**保留并作为示范:

| 演示 | 解释什么 |
|---|---|
| 填报顺序 | 录一笔收入会立即加进账户余额 → 顺序反了会重复计(左右对照,错误侧滚到 ¥36,519 变红) |
| 下钻三步 | 明细抽屉只能从交叉透视的格子点开(旭日缩范围 → 透视定位 → 抽屉落到单笔) |

### FR-252 · 教程页的表现形式可以比功能页更外放

它不是日常高频页面,而是**读物**。允许比功能页更大的标题、更强的装饰、章节编号、
滚动进场与悬停反馈 —— 但仍在现有设计令牌内(纸感底 / Fraunces 大标 / 等宽数字 / 黄铜森绿铁锈三色),
不引入新色系、不加载外部字体、不用 emoji(一律 inline SVG)。

### FR-253 · 新手醒目、老手不打扰

- **醒目**:仪表盘 + 填报页顶部引导卡,`localStorage.manualHintDismissedAt` 一年
- **常驻**:导航栏最末「手册」(PC 主栏 + 移动抽屉)+ 填报页标题旁「怎么填?」
- 导航栏 8 项**全部**配 icon —— 只有一项有 icon 是最难看的状态
