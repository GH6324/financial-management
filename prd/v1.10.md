# v1.10 · 报表页进化为「月度封板快照」

> 状态:待评审
> 目标版本:`app.version = 1.10.0`
> 前置:v1.9.4(已上 prod)
> 预览:`preview/v1.10/reports-snapshot.html`

---

## 0 · 为什么做这一版

维护者定的两页分工:

| 页面 | 代表什么 | 指标性质 |
|---|---|---|
| **仪表盘** | 当期**未封板**的实时数据 | 会变;用来理解"家里现在什么状况" |
| **报表页** | 每月关账后的**封板快照** | **不会再二次变动**;用来做快照分析 |

按这个分工审视现状,报表页现在其实是一张**「收益分析页」**,还不是「封板快照页」。九个 section
里有七个是收益/结构分析,而"封板快照"最该有的三样东西一样都没有:

1. **期末家底** —— 报表页没有总负债、没有紧急储备、没有资产负债率。开头直接给 XIRR,
   等于"没说家底先说收益"。理财师翻开月报第一眼看的是 balance sheet。
2. **可比性** —— 封板快照的**全部价值在于可比**,而现在没有任何环比/同比/两期对照。
   "本月净资产 461 万"是个孤立数字,判断不了异常月还是趋势拐点。
3. **可信度声明** —— 没有"这份快照完整吗"的交代:几个账户已填/未填、估值是自动拉价还是手填、
   汇率是哪天的。不知道完整度的报表没法拿去分析。

### 0.1 一个比补指标更重要的结构问题

理念是"月度封板快照",但页面主框架是**滚动窗口**(`range` = 1M/3M/6M/YTD/1Y/ALL)。
这两者在打架:滚动窗口天生是**趋势**视角,封板是**定格**视角。

v1.9.4 那个财富水位 bug 就是这个张力的产物 —— 窗口一变,"首期"是谁就变,
指标的可用性跟着变。用户关了三期却永远看不到那一节,根因链条的起点就在这里。

所以 v1.10 不只是加 section,而是**把「本期封板」升为第一等公民**:

```
报表页
├─ 一 · 本期封板(定格 · 新)          ← asof 选定的那个已关账期,indicators 全部不再变动
│   ├─ 封板抬头(朱印 + 数据完整度)
│   ├─ 期末资产负债表
│   ├─ 资金流瀑布(期初 → 期末的闭环)
│   ├─ 本期 vs 上期 vs 去年同期(三列对照)
│   └─ 本期归因(谁把净资产推上去/拉下来)
├─ 二 · 结构与风险(定格 · 部分新)
│   ├─ 集中度(新)
│   ├─ 流动性分层(新)
│   ├─ 负债 / 风险等级分布(现有)
│   └─ 资产配置对照 + 调仓建议(现有)
└─ 三 · 趋势(滚动窗口 · 现有全部下沉到这里)
    ├─ 账户级收益 · vs 基准
    ├─ 财富水位
    ├─ 储蓄能力
    ├─ 支出构成
    └─ 本金 vs 投资损益
```

`range` 选择器**只作用于第三区**;第一、二区只认 `asof`(观察账期)。这样"不会二次变动的指标"
这句话才真正成立 —— 前两区的每个数字都只由"哪一期"决定,不由"看多长的窗口"决定。

## 1 · 范围

维护者拍板的切法:**P0 全部 + P1 的集中度 / 流动性 / 本期归因**。
理由是这几项数据**全部现成**、能一版做完且互相支撑(资产负债表给分母,三列对照给可比,
瀑布给闭环校验)。

**本版做**(FR-320 ~ FR-326):

| 编号 | 功能 | 组 |
|---|---|---|
| FR-320 | 页面重构成三区 · `range` 只管趋势区 | 结构 |
| FR-321 | 封板抬头 · 数据完整度声明 | P0 |
| FR-322 | 期末资产负债表 | P0 |
| FR-323 | 资金流瀑布(含恒等式校验) | P0 |
| FR-324 | 本期 vs 上期 vs 去年同期 三列对照 | P0 |
| FR-325 | 集中度 + 流动性分层 | P1 |
| FR-326 | 本期归因 · 正负贡献 Top | P1 |

**本版不做**(记在这里免得反复讨论):

- **币种敞口 / 汇率贡献** —— 要新算"orig 与 base 的差额归因",不是取现成字段 → v1.11
- **目标进度封板** —— 需要在关账时定格(或按已关账期重算),牵动 goal 模块 → v1.11
- **两期任选对比** —— 数据现成但要新的页面态与差异表 → v1.11
- **导出 CSV / 打印样式** —— → v1.11
- **封板月评(AI 话术)** —— → v1.11
- **夏普比 / 波动率** —— **永不做**。月频 12 个点算出来没有统计意义,是假精确。
  最大回撤可以给(账户级已有)。
- **逐笔流水分析** —— 项目非目标,已在 issue #9 对外说明。
- **实时 / 当期未封板指标** —— 那是仪表盘的职责,重复即混淆。

## 2 · 功能需求

### FR-320 · 三区重构 · `range` 只管趋势区

**现状**:`range`(默认 1Y)与 `asof`(观察账期)两个控件并列在页头,同时作用于全页所有 section。

**改为**:

- 页头保留两个控件,但**分工写明**:`账期` 决定前两区定格在哪一期;`范围` 只影响第三区趋势。
- 前两区的所有计算只依赖 `asof` 锚定的那一期(以及它的上一期 / 去年同期)。
- 第三区保持现状,`range` 原样生效。
- 控件位置:`账期` 留在页头;`范围` chips **移到第三区标题旁**,让作用域一眼可见。

**验收**:

1. 切换 `range`,前两区所有数字**逐字不变**(护栏 `v110-SNAPSHOT-RANGE-INVARIANT` 扫)。
2. 切换 `asof`,前两区整体换期;第三区窗口右端跟着锚变(与现状一致)。
3. 无已关账期(外壳态)→ 前两区显示统一空态,不显示半截数字。

### FR-321 · 封板抬头 · 数据完整度声明

朱印「已关账」已有,在它旁边补一行**可信度交代**:

| 项 | 内容 | 数据来源 |
|---|---|---|
| 账期 | `2026-07 月度账册 · 关账于 2026-08-01` | `period.closed_at` |
| 填报完整度 | `20 / 20 个账户已填` · 未填时红字列出前几个 | 填报待办 |
| 估值来源 | `自动拉价 6 · 手填 14` | 账户持仓/估值标记 |
| 汇率 | `汇率日期 2026-07-31` | 汇率快照 |

**验收**:

1. 有未填账户时,完整度那格是 rust 色并给出账户名(点击可跳填报)。
2. 汇率日期取的是该封板期的汇率,不是"今天"的。
3. 非快照态(还没有任何已关账期)不显示这一行,显示引导。

### FR-322 · 期末资产负债表

六格 KPI 带 + 一条**资产/负债对称条**。

| 指标 | 口径 | 已有字段 |
|---|---|---|
| 期末净资产 | 资产 − 负债 | `netWorth` |
| 总资产 | 除贷款外全部 | `totalAssets` |
| 总负债 | 仅 LOAN 绝对值 | `totalLiabilities` |
| 资产负债率 | 负债 ÷ 资产 | `debtToAssetRatio` |
| 流动资产 | LIQUID 合计 | `liquidAssets` |
| 紧急储备 | 流动资产 ÷ 月均支出 | `emergencyFundMonths` |

**验收**:

1. 六格与仪表盘同名 KPI **口径一致**(同一期时数值相等)—— 差异只能来自"锚哪一期"。
2. 三币种切换:金额按 fx 缩放,**资产负债率与紧急储备月数三币种完全相等**
   (币种不变性铁律,`CurrencyInvarianceTest` 已有属性级护栏,新增比率纳入)。
3. 对称条左右两侧同一比例尺(并列同类元素同尺寸铁律)。

### FR-323 · 资金流瀑布(含恒等式校验)

`期初净资产 → +收入 → −支出 → ±投资损益 → 期末净资产`

**这一节的隐藏价值是对账**:上面那条链是个恒等式。

```
期末净资产 − 期初净资产 = (收入 − 支出) + 投资损益
                          └─ 人赚的 ─┘   └ 钱赚的 ┘
```

这个项目最容易出的错就是口径串台(v1.8 支出、v1.9.4 财富水位都栽在这上面)。
所以瀑布不只画图,**还要显式校验等式**:

- 闭合(误差 ≤ ¥1,四舍五入容差)→ 正常显示
- 不闭合 → 图下方给一条 rust 提示,写出差额与可能原因(如"本期有账户首次出现,
  其开账基线 ¥N 属外部资本纳入,不计入损益"),**不假装闭合**

**必须用截断轴**(画预览时才发现的约束):月度**流量**(收入 8.6 万)和**存量**(净资产 461 万)
差两个数量级 —— 全量轴下中间三段柱子会细成一条线,等于看不见。所以:

- 轴的上下界按「期初 / 期末 / 中间累计值的 min-max ± 余量」动态算,**不写死**
- 轴上**显式标注截断**(如"轴自 ¥400万 起 · 截断轴"),**不能默默从 0 起,也不能默默截断**
- 段间要有**连接线**(上一段端点水平延伸到下一段起点)—— 没有连接线就读成普通柱状图,失去"分解"语义

**验收**:

1. 恒等式闭合时不显示提示;人为造一期开账基线 → 提示出现且差额等于开账基线。
2. 瀑布每段的数字**浮在柱上**(datalabels 铁律,hover tooltip 不算)。
3. 负债增加(如新增房贷)方向正确:落在"投资损益"之外,归到开账基线说明里。
4. 轴截断时页面上有明示;五段首尾严格相接(连接线对齐,不出现视觉断层)。
5. 极端情况:某段为 0(如本期无投资损益)不画零高度柱,显示 `—` 并连线直通。

### FR-324 · 本期 vs 上期 vs 去年同期 · 三列对照

**用表不用图** —— 封板要的是精确值,图会让人读不出具体数。

| 指标 | 本期 | 上期 | 去年同期 | Δ 环比 | Δ 同比 |
|---|---|---|---|---|---|
| 净资产 | | | | | |
| 净流入(人赚) | | | | | |
| 投资损益(钱赚) | | | | | |
| 支出 | | | | | |
| 储蓄率 | | | | | |
| 资产负债率 | | | | | |

**验收**:

1. 上期 / 去年同期**不存在**时那格显示 `—`,Δ 也显示 `—`,不显示 0 也不显示 100%
   (新用户第一期必然如此,不能给出误导的 Δ)。
2. 比率类指标的 Δ 用 **pp**(百分点)不用 %;金额类用 % 与绝对值双给。
3. 去年同期取的是**同月**(2026-07 对 2025-07),不是"12 期前"—— 周期类型可能是周度。
4. 三列都只取**已关账**期;上期若未关账则显示 `—` 并注明"上期尚未关账"。

### FR-325 · 集中度 + 流动性分层

**集中度**(现在只有风险等级饼图,看得出结构但月月对比不了 —— 必须是**数字**):

| 指标 | 用途 |
|---|---|
| 最大单一账户占比 | 鸡蛋是否在一个篮子 |
| Top3 账户占比 | 同上,更稳的口径 |
| HHI 赫芬达尔指数 | 单一数字表达整体分散度,适合月月对比 |
| 最大单一平台占比 | 平台风险(跑路/封号)· lens 平台维度现成 |

组件:横向条 + **阈值刻度线** + **上月幽灵条**(淡色叠一条,一眼看出集中度在升还是降)。

**流动性分层**:即时可用 / 半流动 / 不可动 三层占比(`AccountLiquidity` 现成三档)。
组件:单条**堆叠水平条**,段内标金额与占比,右侧标"即时可用可覆盖 N 个月支出"。

**验收**:

1. HHI 定义写进 tooltip(Σ 各账户占比²,0~1,越大越集中),并给参考刻度。
2. 幽灵条在没有上期时不画(而不是画成 0)。
3. 分层占比合计 = 100%;`NA` 档并入"不可动"并在 tooltip 说明。

### FR-326 · 本期归因 · 正负贡献 Top

复用 `AttributionEngine`(仪表盘归因复盘已在用),换成封板期口径。

- 正贡献 Top3 / 负贡献 Top3 账户,给金额与占本期变动的比例
- 本期**新增 / 归档**账户单列(它们不是"赚了钱",是资本纳入或移出)

组件:**双向条形**(零轴居中,正右负左)+ 一句文字归因。

**验收**:

1. 新增账户的开账基线**不出现在**正贡献里(否则"补录一个存量账户"会显示成本月大赚)。
2. 归档账户的移出同理不算负贡献。
3. 贡献之和 + 开账基线 + 移出 = 本期净资产变动(与 FR-323 恒等式同源,互为校验)。

## 3 · 非功能

- **prod 向后兼容**:本版**无 schema 变更**。所有指标从既有事实切片算,不新增表、不改字段。
- **性能**:前两区新增的计算都在已加载的 `FactSlice` 上做,不新增查询;
  上期 / 去年同期需要各多取一期事实 → 复用现有 `load(FactFilter)`,单页最多 3 次切片加载。
- **页面渲染不等网络**:不引入任何外部调用。
- **币种不变性**:新增的比率类指标(资产负债率、储蓄率、集中度、HHI、分层占比)
  必须三币种完全相等,纳入 `CurrencyInvarianceTest` 属性级扫描。
- **长文目录**:三区重构会改 section 结构 → `tocItems` 必须同步(改 section 必同步 TOC 铁律)。
- **移动端**:三列对照表在窄屏首列吸顶 + 横向滚(照 v1.6.31 的做法);
  瀑布与双向条形在窄屏降级为纵向条。
- **无 emoji**:所有新图标走 inline SVG。

## 4 · 验收总览(用户视角走一遍)

1. 登录 → 报表页 → 顶部能看到朱印「已关账」+ 账期 + `20/20 已填` + 汇率日期。
2. 第一屏就能回答"这个月末我家有多少钱、欠多少、能撑几个月"。
3. 往下一屏,瀑布把"净资产为什么变了"讲完,且等式闭合。
4. 再往下,三列对照能看出"本月支出比去年同月高了多少"。
5. 切 `范围` chips → 前两区一个数字都不动,只有趋势区变。
6. 切 `账期` 到上一期 → 整页定格到那一期,数字与当时一致(封板不变性)。
7. 手机端把上面 6 条再走一遍,表格首列吸顶、图不溢出。

## 5 · 风险与对策

| 风险 | 对策 |

| 指标口径与仪表盘不一致,用户看到两个"净资产" | FR-322 验收 1 明确要求同期相等;落护栏比对同期同名 KPI |
