## FR-A · 贵金属账户 + 自动金价(issue #4)

### 背景
现有账户类型覆盖股票 / 现金 / 理财 / 加密 / 房产 / 贷款。黄金及贵金属(白银 / 铂金 / 钯金)是国内家庭常见的避险与配置资产,计价单位(克)、报价机制(有买入价、实时现价)与股票有差异,且价格波动频繁,值得一个专门分类精准管理。

### FR-A1 · 新增「贵金属」账户分类
- 新建账户「类型选择」里增加**贵金属(Gold / Precious Metals)** 分类。
- 一期覆盖常见品种:**黄金、白银、铂金、钯金**。
- 复用现有"持仓账户"能力:一个贵金属账户下可加多笔持仓(如"金条 200g""白银 T+D 1kg")。

### FR-A2 · 计价单位(克 / 盎司)· 账户/持仓属性
- 单位支持 **克(g)** 与 **盎司(oz)**,国内默认 **克**。
- 单位是**持仓自己的属性**(建持仓时选,默认克),不是全局开关 —— 因为用户可能同时持有国内金(按克)与国际金(按盎司),二者互不打架。换算:1 金衡盎司 = 31.1035 克。
- 单位默认跟随所选品种/价格源:选上海 SGE → 默认克;选国际现货 → 默认盎司;用户可改。

### FR-A3 · 字段(每笔持仓)
| 字段 | 含义 |
|---|---|
| 品种 | 金 / 银 / 铂 / 钯 |
| 持仓量 | 总重量,支持多位小数(如 10.55 克 / 1.2 盎司) |
| 买入价 | 购入时每单位单价(每克 / 每盎司,含成本) |
| 最新现价 | 系统自动拉取或手动更新的当前市场价(每单位) |
| 当前总估值 | 最新现价 × 持仓量 |
| 持仓盈亏 | (最新现价 − 买入价) × 持仓量 · 正红涨 / 绿跌按项目既有色板 |

### FR-A4 · 自动拉取实时金价
- 系统后台自动拉取贵金属实时价,支持 **一键"刷新现价"** 与 **定时任务自动更新**(与股票 / 加密同一套节奏配置)。
- **双源内置,管理员可切,默认上海 SGE**:
  - **上海 SGE(默认 · 人民币计价)**:黄金 9999(元/克)、白银 T+D(元/千克)、铂金 9995(元/克)等。
  - **国际现货(美元计价)**:伦敦金 XAU、伦敦银 XAG、铂 XPT、钯 XPD(美元/盎司)。
- 源切换在**接入源配置页**(`/admin/integrations`)完成(见 FR-C),与"股票行情源""汇率源"同页同范式,带一键测试连接。
- **口径注意(给评审)**:SGE 白银报价是**元/千克**,与金/铂的"元/克"不同 —— 系统内部按品种归一到"每克 / 每盎司",用户录入与展示不受影响。

### FR-A5 · 展示与汇总
- 持仓页按品种列出:持仓量(带单位)、买入价、最新现价、总估值、盈亏。
- 贵金属账户总估值并入净资产 / 总资产 / 资产配置环(与其它账户口径一致);跨币种(SGE=CNY / 国际=USD)经既有本位币 / 视图币种镜头换算,比值类指标保持币种无关([[feedback_currency_invariance]])。

## FR-B · LLM 供应商由管理员自选(我们只给默认)

### 背景 / 现状
系统的 AI 能力(资产体检 / 月报 / 目标向导 / 调仓建议 / AI 洞察)已统一走同一套 LLM 客户端链,当前逻辑是"谁配了 key 用谁 + 故障自动切备",但**主备优先级写死**(Qwen 恒为主、DeepSeek 恒为备),管理员无法选"以谁为主"。采样温度也写死。

### FR-B1 · 主选供应商可配
- 接入源页 LLM 段新增「**主选 AI 供应商**」:Qwen / DeepSeek,**默认 Qwen(推荐)**。
- 主选故障时自动切到另一家(沿用既有 failover);两家都配了 key 才有切换意义。
- 与既有"一键测试连接"配合:配好 key + 选主选后可一键验通。

### FR-B2 · 采样温度可配
- 新增「采样温度 temperature」:0.0(确定)~ 1.0(发散),**默认 0.5**,实时生效。

### FR-B3 · 模型 = 随供应商级联的下拉(不手打型号)
- 「模型」**不做成手填输入框**,而是**下拉**,选项**随"主选供应商"级联**:选 Qwen → 列 Qwen 系模型(qwen-plus / qwen-flash / qwen-max);选 DeepSeek → 列 DeepSeek 系模型(deepseek-chat / deepseek-reasoner)。
- 每家默认「**自动(推荐)**」:Qwen 保留既有"多模型轮询摊免费额度"策略,DeepSeek 用其默认模型;用户想钉死某个型号时再从下拉里选。
- 候选型号清单是**系统内置、随版本维护**的,不暴露自由文本 —— 避免打错型号导致调用失败。

> 不改动:各处 AI 调用的业务 prompt、合规校验、脱敏红线一律不动(那是系统设计核心,见 [[feedback_llm_no_math]] / [[feedback_llm_validator_diagnosis]])。本 FR 只放开"用谁、多随机、备源模型名"。

## FR-C · 运营配置开放梳理(该开的开)

目标:凡"系统级运营参数(接入源 / 阈值 / 节奏 / 手机号)"都应能在管理页配、只给默认([[feedback_admin_runtime_config]]);但**不把工程内部旋钮一股脑丢给非技术家属**(违背 10 分钟/月红线,徒增误配风险 —— [[feedback_decision_weight_honesty]])。故分三桶:

### 桶一 · 已可配(保持,列全备查)
接入源页:Qwen/DeepSeek Key、max_tokens、timeout、Qwen 模型池、股票拉取开关 + 美/A/港/加密各自 cron、汇率 cron、CPI/M2 手录。
调优页:转账提示额、贷款异常倍数、余额容差、体检集中度 / 高风险占比 / 流动性 buffer / 应急金月数、remember-me 有效期。
提醒页:填报模板、提前天数、短信开关 + 阿里云 aksk / 签名 / 模板、成员手机号。
家庭页:本位币、周期类型、CPI 假设、配置锚点、风险偏好、Logo / 品牌名。
指标页:家庭级 / 账户级指标勾选。

### 桶二 · 本次开放(写死但该给管理员)
| 项 | 现状 | 放哪 | 默认 | 类型 |
|---|---|---|---|---|
| **LLM 主选供应商** | 写死 Qwen 为主 | 接入源页 · LLM 段 | qwen | enum(qwen/deepseek) |
| **LLM 采样温度** | 写死 0.5 | 接入源页 · LLM 段 | 0.5 | double 0–1 |
| **LLM 模型(级联下拉)** | DeepSeek 写死 deepseek-chat / Qwen 池 | 接入源页 · LLM 段 | 自动(推荐) | enum · 随供应商级联 |
| **贵金属价格源** | (新功能) | 接入源页 · 贵金属段 | 上海 SGE | enum(sge/intl) |
| **贵金属拉价 cron** | (新功能) | 接入源页 · 贵金属段 | 每日一次 | cron |

### 桶三 · 保持内部(梳理到了,但**不开放**,附理由)
| 项 | 为什么不进管理页 |
|---|---|
| 熔断失败阈值 / 冷却时长、Qwen 模型额度冷却 / 上限 | 纯工程自愈参数,非技术家属永远不碰;默认已合理,开放只增困惑与误配 |
| LLM 诊断 / 调仓缓存 TTL、输出字数上下限 | 内部质量 / 成本旋钮,与用户目标无关 |
| 调仓金额上限比例、估值事件阈值 | 内部安全阈值,乱调会出坏建议 |
| FIRE 三情景利率 / 提取率 / 通胀区间 | 决策 22 明确不许用户改(避免自欺式乐观假设);系统级默认已锚定 4% 法则 |
| remember-me key、种子管理员密码、端口 / 数据库 / API 端点、系统 prompt | 安全敏感 / 基础设施 / 质量核心,改了会坏或有安全风险,留 env/代码 |

> 原则:**"用户能感知、且会去调"的才开放;工程为了自愈/省钱/防呆设的旋钮留在代码。** 桶三里将来某项真有人要,再单独开,不在本版铺开。

## 非目标
- 不做贵金属**实物交割 / 手续费明细 / 买卖挂单**(只做"持有量 × 现价"的估值与盈亏)。
- 不引入新的付费行情供应商;只用已验证可直连的公开源(SGE / 国际现货,复用现有新浪主源基础设施)。
- 不改各处 AI 的业务 prompt / 合规校验 / 数学禁令。
- 不把桶三的工程旋钮开放到管理页。

## 验收标准
1. 新建「贵金属」账户 → 加一笔"黄金 200 克 · 买入价 500 元/克" → 一键刷新现价(SGE Au9999)→ 显示总估值 ≈ 现价×200、盈亏 =(现价−500)×200;数字精度不被截断(承 v0.13.1)。
2. 建持仓时可选单位克/盎司,盎司仓的估值 / 盈亏按 1oz=31.1035g 与 SGE 克价正确换算。
3. 白银(SGE 元/千克)持仓估值口径正确(内部归一,不串成"元/克")。
4. 贵金属账户估值并入净资产 / 总资产 / 配置环;三视图币种下比值类指标完全相等。
5. 接入源页可切价格源(默认上海 SGE)、可设拉价 cron、可一键测试连接。
6. 接入源页可选主选 LLM(默认 Qwen)、设 temperature(默认 0.5)、DeepSeek 模型名;改「主选=DeepSeek」后,AI 体检/月报等确实先走 DeepSeek,故障回退 Qwen。
7. 桶一已可配项行为不回归;桶三项仍按默认工作、未出现在管理页。

## 评审结论(已定 · 2026-07-08)
1. 单位 = **持仓级属性**(建仓时选克/盎司,默认克),不设全局默认。✓
2. 品种 = **金 / 银 / 铂 / 钯 全做**(一期全上)。✓
3. 账户类型 = **新增独立「贵金属」类型**(与加密对称)。✓
4. LLM 主选 = **默认 Qwen**,可切 DeepSeek。✓
5. 配置开放"桶二/桶三"切分 = **按现状**(不挪动)。✓
6. 全部配置 = **放现有「数据源接入」一页**(不拆子页)。✓
7. LLM「模型」= **随供应商级联的下拉**(不手打型号,默认「自动(推荐)」)。✓ (评审补充,见 FR-B3)
