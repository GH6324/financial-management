# PRD · v0.16 · 目标模块重构:通用追踪目标 + 移动端瘦身

> 关联 GitHub issue #5(近期/中短期资产冲刺目标)。本版把「财务目标」从三类固定预设,重构为**通用追踪目标**:一个目标可绑定 0–多个账户,选一个**追踪指标**(金额 / 收益率),设一个**目标值**与**时间范围**;旧的退休 / 教育 / 应急三类作为**智能预设**完整保留。并顺带优化多目标在手机上的排版。

## 1. 背景与动机

- 现状:目标只有 RETIREMENT / EDUCATION / EMERGENCY 三类,口径写死(退休/教育=全家净资产,应急=全家现金),**无法绑定具体账户,也无法自定义追踪什么、追到什么时候**。
- issue #5(用户 BetterQx):想要「今年存款到 20 万」「3 年内首付存够 50 万」这类**明确期限 + 目标金额 + 指定账户范围**的中短期冲刺目标,并要倒计时、达标率、以及「进度落后于时间进度」的提醒。
- 用户进一步诉求(本次拍板):目标应能**绑定 0–多个账户**并选**追踪指标**(账户金额、收益率),从而表达如:
  - 「某个账户的金额达到 X」
  - 「某 3 个账户合计的年度收益率达到 20%」
- 多目标在手机上太占地方,需要瘦身。

## 2. 术语

- **追踪指标(metric)**:目标盯着的那个数,来自绑定账户(或全家)的衍生指标。**与账户/报表的指标目录(`MetricPrefsService.ACCOUNT`/`FAMILY` + `AccountPerformance` 全字段)一一对应**,凡账户视图里算得出的都能作目标。按语义分三组:

  **① 金额类**(Σ 绑定账户本位币,0 账户=对应全家总量;可算「达标率 + 时间落后判定」):
  - `金额合计`(current_value)— 绑定账户当前价值之和;0 账户 = 全家净资产。
  - `现金合计` — 绑定账户现金口径之和;0 账户 = 全家现金(兼容应急)。
  - `累计净投入 / 本金`(net_principal)— 你实打实投进去的钱(存款冲刺最贴切)。
  - `累计投资损益`(cum_pnl)— 赚到的钱累计到 ¥X。
  - `本期损益`(period_return / latestPnl)。
  - `总资产`(total_assets)/ `总负债`(total_liabilities,方向为「降到 ≤」)。

  **② 比率类**(百分比;只给倒计时,不做时间落后硬判定 · FR-16-4b):
  - `年化收益率`(xirr,原币剔汇率)/ `本位币收益率(含汇率)`(return_base)。
  - `占家庭比重`(share_pct)— 这几个账户占家庭净资产达到 X%。
  - `环比 MoM %`(mom_pct)。
  - `储蓄率`(savings_rate,家庭级 · 0 账户)。
  - `最大回撤`(max_drawdown,方向「控制在 ≤ X%」· 进阶)。

  **③ 月数 / 其它**:
  - `紧急储备月数`(emergency_months)— 现金 ÷ 月支出达到 N 个月。

  聚合口径:金额类求和;比率类按价值加权(收益率复用账户级收益 + 家庭 TWR;0 账户=全家 KPI);占比 = Σ绑定价值 / 净资产。收益率/回撤对不可算收益的账户(现金/房产)无意义,勾选时提示。
- **目标范围(scope)**:该目标绑定的账户集合,0..N;0 = 全家。
- **达标判定**:`≥ 达到`(金额/收益率增长类,多数)或 `≤ 降到`(总负债、最大回撤等收敛类)。方向按指标默认给出,用户可改。不做「区间/介于」。
- **时间范围**:
  - `截止型`:有截止日(快捷 1 年 / 3 年 / 5 年内,或自定义日期)。
  - `长期型`:无期限(旧退休/教育/应急默认此类;退休/教育内部仍有推导的达成年份)。
- **预设(kind)**:`退休 FIRE` / `教育金` / `应急储备` / **`自定义追踪`(新增)**。前三类携带各自的参数向导与目标值推导,自定义追踪是通用模型的直接暴露。

## 3. 功能需求(FR)

### FR-16-1 · 通用目标数据模型
每个目标具备:名称、预设类型(kind)、追踪指标(metric)、绑定账户集合(0..N)、目标值、达标判定(≥)、时间范围(截止日或长期)。旧三类目标无损映射为该模型的特例(见 FR-16-8)。

### FR-16-2 · 新建「自定义追踪目标」(issue #5 核心)
在「新建目标」入口新增第 4 张卡「自定义追踪目标」。向导:
1. 起名(如「今年现金冲刺」)。
2. **选追踪指标**:金额合计 / 现金合计 / 收益率·年化 / 收益率·YTD。
3. **勾选账户**(多选,0..N;可全选/清空)。指标为收益率时提示只对可算收益的账户(股票/理财/加密/贵金属)有意义。
4. **填目标值**:金额型填金额(账户记账币种按视图币种折算展示);收益率型填百分比(如 20%)。
5. **选时间范围**:快捷「1 年内 / 3 年内 / 5 年内」自动生成截止日;或「自定义日期」;或「长期(不设期限)」。
6. 保存 → 目标详情。

### FR-16-3 · 达标率与倒计时
详情/列表展示:
- **达标率** = 当前指标值 / 目标值 ×100%(收益率同理,负收益显示为落后)。
- **倒计时**(截止型):距截止日还有 N 天;并显示「时间已过 X%」。

### FR-16-4 · 进度 vs 时间 落后提醒(issue #5)
截止型目标对比「达标率」与「时间进度」:
- 达标率 ≥ 时间进度 → `进度良好 / 领先`(forest)。
- 达标率明显落后于时间进度(差值超过阈值,如 15pp)→ `进度落后`(rust)提醒。
- 长期型不做时间对比(退休/教育仍用既有三情景达成年份)。

文案示例:「目标 20 万 · 当前 15 万(75%)· 还剩 145 天(时间已过 60%)· 进度良好」。

### FR-16-4b · 收益率型目标的表达
收益率型无「累计到某数」的线性时间进度语义,达标率 = 当前收益率 / 目标收益率;时间对比可选展示(默认展示倒计时,不做落后判定,避免误导),用文案「当前 12.3% / 目标 20% · 还剩 82 天」。

### FR-16-5 · 账户绑定后的口径
- 金额合计:Σ 绑定账户当前余额(按视图币种折算);贷款账户计负;0 账户 = 全家净资产。
- 现金合计:Σ 绑定账户中现金口径;0 账户 = 全家现金。
- 收益率:绑定账户组的价值加权收益率(复用账户级收益 + 家庭 TWR 口径);0 账户 = 全家。
- 绑定账户被归档/删除:目标自动忽略该账户并在详情提示「N 个绑定账户已失效」。

### FR-16-6 · 编辑 / 归档
可改名称、指标、绑定账户、目标值、时间范围;归档为软删(与现状一致)。改动后达标率即时重算。

### FR-16-7 · 移动端瘦身(多目标不再占满屏)
- 手机上目标列表默认为**紧凑条**:每条一行 = 目标名 + 迷你进度条 + 达标率% + 状态点(forest/brass/rust)+ 倒计时;点开才展开详情。
- 一屏可见多条(旧版每目标一张大卡,3 个就刷很久)。
- Dashboard 顶部目标条带同步瘦身:手机上横向可滑的紧凑 chip,或最多 2 条 + 「查看全部」。
- 桌面端保留信息密度更高的卡片,但也压缩每卡高度。

### FR-16-8 · 旧三类目标兼容(零丢失)
- 退休 FIRE / 教育金 / 应急:参数向导、目标值推导、三情景预测、AI 月报、FIRE 自动支出**全部保留不变**。
- 内部映射:退休/教育 → metric=全家净资产、scope=全家、长期(内部有推导达成年份);应急 → metric=全家现金、scope=全家、长期。
- 列表/详情统一用新的进度组件渲染,三类的「三情景达成年份」作为长期型的补充展示。

### FR-16-9 · 新建入口与列表
- 「新建目标」选择页:4 张卡(退休 / 教育 / 应急 / 自定义追踪),自定义追踪卡文案偏向 issue #5 场景(「1 年内存到 X」「某几个账户收益率到 X%」)。
- 列表页:截止型目标按剩余天数升序靠前(临期在前),长期型在后。

## 4. 非目标 / 边界

- 本版不做「目标之间的依赖 / 里程碑拆分」。
- 收益率型目标不做「时间进度落后」硬判定(语义不线性),只给倒计时。
- 不引入新的外部数据源;所有指标复用现有账期快照 + KPI + 账户收益计算。
- 达标判定支持「≥ 达到」与「≤ 降到」两向(按指标默认);不做「区间/介于两值之间」。

## 5. 兼容性与迁移(概要,细节入 tech-design)

- 单表 `family_goal` 扩列:`metric`(VARCHAR)、`comparator`(默认 GTE)、`time_mode`(DEADLINE|OPEN)等;新增关联表 `goal_account(goal_id, account_id)` 承载 0..N 绑定。
- 存量三类目标迁移:kind 保持,metric 回填(净资产/现金),scope=空(全家),time_mode=OPEN;`target_value`/`target_date`/`params_json` 原样保留。**对线上数据零破坏**(纯加列 + 新表)。
- 向后兼容红线遵循 [prod 已上线] 规则:加列可空、旧行为默认不变。

## 6. 验收要点(用户视角走查)

- 新建「自定义追踪目标」:金额型(绑 1 账户,目标 20 万,1 年内)→ 详情显示达标率 + 倒计时 + 落后/良好状态。
- 新建收益率型(绑 3 账户,目标年化 20%)→ 详情显示当前收益率/目标 + 倒计时。
- 0 账户金额型 = 全家净资产,与旧「退休」口径一致。
- 手机上创建 3 个目标:列表为紧凑条、一屏多条、可点开;Dashboard 条带不再刷屏。
- 旧退休/教育/应急目标:三情景、AI 月报、参数编辑一切照旧。
- 归档某绑定账户 → 目标提示失效并重算。
