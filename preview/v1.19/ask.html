问一问 —— 把资产讲给你听

六个 AI 入口至今都是「我们替你问」:我们挑好事实、填进固定 prompt、渲染成固定卡片。 这一版换成「你自己问」—— 我们只维护 agent 的系统提示词与工具清单,由它自己决定调什么。

7刻意不做
不做为什么
常驻助手气泡 / 每日播报 / 主动推送硬约束是每月 10 分钟。这个功能是问一次就走,不是养一个天天要理的东西
让用户自定义 prompt / 建自己的 agenttemplate 是我们的产品责任。用户改了出错我们无从复现,而且禁数学那条会被绕过
消费品类分析(「外卖花了多少」)颗粒度停在账户级月度快照,消费品类细化在刻意不做清单里
预测涨跌 / 荐具体产品现有六处 AI 的边界,不因为换成对话就放开
多 agent / 工作流编排一个 agent 够用。多 agent 是把复杂度前移到我们身上,用户感知不到
PC / 移动分开设计就是一个 SSE 对话流,一套响应式(你的原话:「不都很低成本嘛」)。上线双端各截图核对排版
