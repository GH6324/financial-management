保险账户 · 储蓄 / 理财型

把有现金价值的储蓄 / 理财型保险(年金险 / 增额终身寿 / 万能险 / 分红险)纳入家庭资产大盘。保险账户 = 又一类「按周期手填当前价值」的资产账户,复用现有估值 / 净资产 / 配置链。关联 issue #6。

第 9 类账户 · INSURANCE 现金价值 = 手填余额 计入总资产 / 净资产 保单登记字段 · 可选 不做预算引擎 · 不算保单收益
坚 · 持 · 原 · 有 · 账 · 户 · 理 · 念
① 保险账户 = 手填「现金价值」的资产账户,和理财 / 房产 / 贵金属同一套估值链,不新增估值范式。 ② 不引入预算 / 现金流预测引擎(issue 里的"自动生成流出预算"我们不做)—— 保费只作登记,真实流出由每期余额变化 + 现有净流入自然捕获。 ③ 消费型保险(车 / 医疗 / 定期寿)不建账户(无现金价值 = 纯支出)。 ④ 不替系统 / LLM 算保单收益(演示利率不可信 · LLM 禁数学)。
