自定义支出分类 + 支出报表

中心决定只有一个:逐笔归 APP,分类归我们。数怎么进来给三条通道(手抄 / 文件导入 / AI 截图),殊途同归到同一个确认页。 流水账留在支付宝/微信/银行 APP 里,月底把它们账单上的分类汇总照抄进来 —— 和现在抄一个总数是同一个动作、同一个时点,只是从 1 个数变成几个数。 分类是总额的「展开」,不是第三种记账方式:合计自动写回月度总额, 家庭支出的所有口径(储蓄率/月均/紧急储备/FIRE)一行不改。不用这套的人,一个像素都不变。

一数怎么进来 · 三条通道一个出口 FR-530~545 · 渠道档案(交互/产物/截图页)+ 来源行合并模型(PRD §1.2 / §1.2b)
三条通道:① 手抄(照账单抄数,零依赖)· ② 文件导入(支付宝/微信)· ③ AI 截图(任何渠道的统计页,qwen-vl 只转写不算数)。下面是渠道档案(逐步路径将来原样进导入页指引,页脚标核对日期 + 失效反馈):
渠道档案 · 支付宝 文件 + 截图
文件导出(逐步):我的 → 账单 → 右上「···」→ 开具交易流水证明 → 选「用于个人对账」(⚠ 别选证明材料,那是盖章 PDF)→ 支付密码 → 范围最长 1 年 · 勾选「展示交易对手/商品说明」 → 填邮箱 → 密码走「支付宝服务消息」推送(开具记录里也能查)
产物:zip(加密)→ csv · GBK · 前 ~24 行说明(按表头特征定位不写死)· 12 列含「交易分类」「收/支」「交易状态」 · 金额可能带 ¥ 和千分逗号
解析口径:只取「支出」· 退款按同分类净额轧抵 · 转账红包/投资理财/保险进中性清单(确认页可改)
截图目标页:我的 → 账单 → 月账单(分类统计,可切按年)
渠道档案 · 微信 文件 + 截图
文件导出(逐步):我 → 服务 → 钱包(老版:我 → 支付 → 钱包)→ 右上「账单」→ 等加载完 → 「常见问题」→ 下载账单 → 「用于个人对账」→ 范围一次最多 3 个月(整年分 4 次)→ 邮箱 + 支付密码 → 密码在「微信支付」通知里,先记密码再去邮箱
产物:zip(加密)→ csv · UTF-8(与支付宝不同,引擎自动分流)· 前 ~16 行说明 · 11 列,没有消费分类列(交易类型只有商户消费/转账/红包)
解析口径:只取「支出」· 零钱充值/提现/理财通/还卡进中性清单 · 商户关键字 → 类目(规则可编辑记忆化,不命中落「其他」)
截图目标页:钱包 → 账单 → 右上「统计」(月账单收支构成,可切年)
渠道档案 · 招商银行 / 工商银行 第一期只走截图
截图目标页:招行 App 首页「收支明细 / 月账单 · 结余月历」(自带四十余种场景分类);工行 App 收支统计页同理。
文件路径(记录在案,暂不接):招行 App「流水打印」= PDF,结构化要走网银导 Excel;工行 App「历史明细打印」/ 网银导 csv —— 各行格式不一,等真实样本再写解析器,不瞎写。

· 重导渠道 X → 只替换 X 的行,手填与他渠道不动(确认页显示差额)
