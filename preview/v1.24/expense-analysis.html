支出分析:从「摆出来给你看」到「所以呢」

v1.21/v1.22 把进数做完了 —— 账单能导、逐笔能改、分类能自定义。现在 cash_flow 里躺着一批带分类的逐笔支出,而读这条线只有三块:本期构成、年度累计、12 期趋势。 三块都在「摆出来给你看」,没有一句「所以呢」。
更要紧的是:月均支出在这个 app 里不是展示字段,是承重结构 —— 紧急储备月数、应急金目标、体检流动性、FIRE 年限全都吃它,而它今天是一个被装修、买车、 旅游污染的扁平 12 期平均。这一版的第一价值不是「你花太多了」,是让那几个指标变诚实。

竞品调研的结论先说

鲨鱼记账 / 钱迹 / 随手记 三家的支出分析重心全在预算 + 超支预警 —— 而 AGENTS.md 把「预算包络」 写进了刻意不做。照抄等于跑偏。海外的 Copilot Money($95/年)主动放弃了预算, 定位是 "tracker, not a concierge";Monarch 的 Flex 预算把支出分成「固定 / 非月度周期 / 弹性」 —— 和我们独立想出来的刚性 / 弹性 / 一次性是同一个抽象。 差别在用途:他们拿它定预算,我们拿它修分母。 只有我们同时握着净资产、流动资产和 FIRE 目标 —— 这件事他们结构上做不了。

最危险的一件事 · 为什么是双读数不是换口径

「用常态月均替换月均支出」只要改一行代码,而且测试会全绿(测试数据里没有一次性笔)。 但它会让每一个现存用户的紧急储备月数、应急金目标、体检流动性评分在升级那一刻全部改变, 而他们什么都没做。
所以:既有数字逐字不变,常态月均作为并列的第二个读数出现。 用户自己判断哪个更贴近自家情况 —— 这比我们替他决定更诚实,而且 两个数摆在一起本身就是信息:差多少 = 一次性支出对判断的干扰有多大。
配套:零差异基线(基线取自已发布 tag v1.23.0,不是当前 master)+ 护栏 v1240-EXISTING-KPI-UNCHANGED(静态扫 averageExpense 没有读新列)。

判据为什么这么保守

我们没有商户字段。导入时商户名被 trimNote() 塞进了 cash_flow.note(BillCommitService.java:175), 而 note 同时装着手填备注。
所以判据只能是:同类目 + 金额落在同一个 ±5% 区间 + 连续 ≥3 期。 note 只做展示标签,不参与判定。

为什么不交给 AI 去认

全在服务端工程代码里做,不调 LLM。 判据是确定性的:可复现、可解释、出了问题能指到代码行。 LLM 做这件事既不可复现也解释不了,而用户看到一条误判时第一个问题就是「凭什么」。
AI 在这一版只干一件事:把工程算好的数字写成一句人话(FR-653)。

9这一版明确不做 每一条都有理由,不是没想到
不做为什么
预算 / 超支预警AGENTS.md 明文「刻意不做预算包络」。预算是月度自律工具(每天看),我们是资产决策工具(每月看一次),10 分钟/月只装得下后者。Copilot Money 主动放弃了预算 —— 这是一个独立佐证。
任何价值判断的文案不说「冲动消费」「你这个月花超了」「建议减少」。少数派那句「花钱永远没有对错」是这一版的红线。系统的职责是指出变化,不是评判选择。配 qa-run 护栏 v1240-NO-JUDGEMENT 扫判断词。
商家 / 交易对象维度没有商户字段,商户名和手填备注混在同一个 note 里。在脏的自由文本上做聚合,产出的排行榜看起来很专业但是错的。要做得先加 counterparty 列。
分类同比需要 13 期的分类数据,v1.21 发布不到一个月。总额同比可以做。
记账激励(打卡 / 徽章)那是留存设计。我们的用户每月来一次,不需要被激励留存。
自定义统计周期账期是一等公民,v1.23 刚把它的边界做成可配置。再叠一层独立统计周期 = 两套时间口径。分析周期 = 账期,不给第二个。

回滚回 jar 即可。数据不需要回滚 —— 没有任何金额依赖这两列。
11等你裁的四件事 PRD §13 的同一份清单
  1. 双读数 vs 直接换口径。我选了双读数。如果你认为常态月均本来就是更对的那个口径、该直接换 —— 那就是一次真正的口径变更,要走「默认关 + 零差异基线 + 页面写明口径期」的完整流程。
  2. 逐笔「一次性」勾要不要做。它是本版唯一增加录入动作的东西(一年 3–5 次)。没有它,「购物类目里买了台电脑」只能靠改整个类目的性质来处理 —— 那是错的。
  3. 周期性判据的松紧。现在是「同类目 + 金额 ±5% + 连续 ≥3 期」。提到 4 期准确率更高,但新订阅要 4 个月才被发现。
  4. 章节顺序。我排成「先结论后明细」(新块在前)。保守做法是加在现有三块后面 —— 老用户阅读习惯完全不变,但「所以呢」又排到了「摆出来给你看」的后面。
