旭日下钻 · 可选分析指标

旭日不再只能看「金额」。像交叉表一样,选一个分析指标(金额 / 本期收益额 / 累计收益额 / 累计收益率),再按任意维度下钻,直接呈现在旭日上。 点旭日中心圆也等于「想换个指标分析」。(demo 为仿真数据 · 后端零改动:复用 /lens/query + PivotEngine 已算好的全部指标)

指标 可加? 弧长 颜色 中心圆 行业/地域降级
金额(默认)是= 金额维值配色(现状)合计 ¥X无影响
本期收益额是(带±)= |收益额|绿赚 / 赭亏(深浅按幅度)净收益 ±¥X不可归因 → 灰置+提示
累计收益额是(带±)= |收益额|绿赚 / 赭亏累计 ±¥X持有口径(市值−成本)仍可
累计收益率否(比率)= 市值(不能按比率分角)颜色=收益率热力(绿高→赭负)整体 +X.X%不可归因 → 灰置+提示

两种模式:可加金额类 → 弧长就是该指标(收益额取绝对值、正负用色);不可加比率类 → 弧长仍是市值、把指标画成颜色热力(诚实,不假装能按比率分角)。
