# Tech Design · v1.2.2 · 全局字号调节(issue #7)

> 配套 `prd/v1.2.2.md`。核心不变量:**标准档(scale=1)全站逐像素等价现状**——所有缩放点都是 `calc(x*var(--fs-scale,1))`,scale=1 时 = x,零回归;只有用户主动选大/特大才变。

## 1 · 架构选型(关键决策 + 取舍)

### 决策 A · 如何让"所有字号"跟随一个开关

| 方案 | 做法 | 取舍 | 选定 |
|---|---|---|---|
| A1 CSS `zoom` / `transform:scale` 整体拉伸 | 一个容器 `zoom:1.15` | ✅ 一行覆盖一切 · ❌ **canvas 图表被光栅拉伸变糊**、扰乱 `position:fixed` 与媒体查询、缩放的是"像素"不是"排版" | ✗ |
| A2 只改根 `html{font-size}` | rem 类自动缩放 | ✅ 零改动覆盖 rem · ❌ **820 处写死 `text-[Npx]` + 组件类 + 图表 JS px 纹丝不动 → 半缩半不崩** | ✗(单独不够) |
| **A3 单变量 `--fs-scale` 驱动五层** | 根字号 + 写死类重定义 + 组件类 calc + 图表 JS 乘 + iOS 地板,全部乘同一个 `--fs-scale` | ✅ 文字/间距一致缩放、图表清晰(矢量重绘非拉伸)、标准档逐像素等价 · ❌ 需分层落地(一次性工程量) | **✓** |

**选 A3**:唯一能做到"全覆盖 + 不糊 + 零回归"的路径。工程量集中在一次性分层,之后维护成本低(新写 `text-[Npx]` 若不在 6 个既有尺寸内才需补一条)。

### 决策 B · 写死的 820 处 `text-[Npx]` 怎么收

| 方案 | 取舍 | 选定 |
|---|---|---|
| B1 逐处改模板(820 处→rem/em) | ❌ 820 处跨 57 文件、易漏易冲突、review 噩梦 | ✗ |
| **B2 重定义 6 个离散尺寸类** | 全站只用了 8/9/10/11/12/13px 六种 → style.css 加 6 条 `.text-\[Npx\]{calc×scale !important}` 一网打尽;`!important` 压 Play CDN 生成的绝对 px(仓库既有手法 `lens-select .lsel-q 16px !important` 已验证) | **✓** |

**选 B2**:O(6) 非 O(820)。无头实测已证:标准 10px → 大 11.5px → 特大 13px,`!important` 稳压 Play CDN。

### 决策 C · 图表 canvas 字号(CSS 够不到)

| 方案 | 取舍 | 选定 |
|---|---|---|
| C1 不管 | ❌ 图表标签冻住 = 半缩,露馅 | ✗ |
| **C2 JS 助手 `chartFont(base)=round(base×scale)` + 渲染时读** | 各图表 `fontSize:N`/`font:{size:N}` → `chartFont(N)`;标准档 =N 等价;每个图表脚本本地兜底 `var chartFont=window.chartFont||(b=>b)`(防 fragment 单独渲染崩) | **✓** |

**重绘策略**:归因图显式监听 `fontscalechange` 重绘(全局单次绑定 + 指针指最新 boot,防 HTMX 重换片累加);dashboard region 每 90s 自刷 → 净资产/配置等 Chart.js 图自动跟档;其余页(报表/体检/账户/目标/透视)图表**下次导航即正确**(切档时若正看着,该图滞后到下次加载,自愈,非"排版坏")。

### 决策 D · 档位形态 / 幅度 / 记忆 / 控件位置

- 离散三档 `标准1.0 / 大1.15 / 特大1.30`(非滑块:家人好懂、可穷尽验证)。
- `html[data-fs="lg|xl"]` 设 `--fs-scale`;标准不设属性(= :root 的 1)。
- **localStorage 按设备**(无障碍偏好跟设备,不入库、不跨端、零后端)+ head 顶 FOUC 内联脚本(DOM 前设好 `data-fs`,避免大字号闪一下再缩,复用隐私模式范式)。
- 控件:PC nav 内 `Aa` 下拉三档;移动 ☰ 菜单内「字号」行三按钮;`[data-fs-opt]` 统一 `aria-pressed` 高亮,双端同步。

## 2 · 落地面(文件级)

- **style.css**:`:root{--fs-scale:1}` + `html[data-fs=lg/xl]` 档位;全部 `font-size:Npx`→`calc(Npx*var(--fs-scale,1))`(base 根字号 + 32 组件类,一条 perl);末尾层2(6 类 `!important`)+ 层5(移动 input 16px 地板,**限 lg/xl** 故标准零改动)+ 控件样式 `.fs-opt/.fs-opt-m`。
- **fragments/layout.html**:FOUC 内联脚本;全局 `FS_STEPS/currentFontScale/appFontScale/chartFont/setFontScale`(设属性 + 存 localStorage + 同步高亮 + 派发 `fontscalechange`)+ DOMContentLoaded 同步高亮。
- **fragments/nav.html**:PC `Aa` 下拉 + 移动 ☰「字号」行。
- **图表页**(dashboard `_attribution`/`_region`、reports `_region`/`_wealth-level`/`_savings`、checkup `account`/`family`、accounts/goals detail、lens.js):`fontSize/font.size`→`chartFont()`,lens 引线 `font:'Npx…'`→`chartFont(N)+'px…'`、注入 pivot CSS px→calc;`_attribution` 加 `fontscalechange` 重绘。

## 3 · 回归防线

- **不变量测试**:qa 守护断言 6 个 `text-[Npx]` 重定义存在 + `calc(...var(--fs-scale`)、FOUC 脚本、控件、`chartFont` 助手。
- **真机验收**:无头 Chromium 三档(标准/大/特大)× 桌面/移动,断言 ①标准档与改动前逐像素一致(关键页对比)②大/特大档 `text-[10px]` computed 随档变 ③移动端各对齐/pill/流水/图例不坏。
- **非目标**:不做字体族切换 / 深色模式 / 逐元素自定义(见 PRD §6)。
