# Tech Design · v1.3 · 旭日下钻 · 可选分析指标

> 配套 `prd/v1.3.md`。核心结论:**后端零改动** —— `/lens/query` + `PivotEngine` 早已算全部 5 指标,旭日只是"只请求了 value"。补齐 = 纯前端。

## 1 · 架构选型(关键决策 + 取舍)

### 决策 A · 旭日如何取多指标数据

| 方案 | 做法 | 取舍 | 选定 |
|---|---|---|---|
| A1 新增旭日专用端点 | 后端算旭日两级 + 指标 | ❌ 违背"唯一分析端点"架构;重复 PivotEngine | ✗ |
| A2 前端对 value 查询再求收益 | 旭日拿头寸自己算收益 | ❌ 前端重算收益口径 = 与 PivotEngine 不一致;比率无法在前端正确聚合 | ✗ |
| **A3 复用 /lens/query · 换 spec** | `rows=[内] cols=[外] measures=[metric,value]` | ✅ 零后端;`rowTotals` 给内环父级**引擎级正确聚合**;比率父级由引擎算(非前端求和) | **✓** |

**A3 关键**:旧旭日用 `rows=[内,外] measures=[value]` 然后**前端求和**得内环值 —— 对 value 正确,但对**比率(cumReturn)错**(父级收益率 ≠ 子级之和)。改 `rows=[内] cols=[外]` 后:`cells` = 内×外(子级)· `rowTotals[i]` = 内环 i 的**引擎聚合**(比率按 Σpnl/Σ本金 正确算)· `grand[mi]` = 整体指标(中心圆直接用)。

### 决策 B · 不可加指标(收益率)怎么画在旭日上

旭日本质 = **部分-整体(可加)**图,弧角 = 值占比。

| 方案 | 取舍 | 选定 |
|---|---|---|
| B1 弧长 = 收益率 | ❌ 比率不可加,父级 ≠ 子级和,角度无意义;负率更无解 | ✗ |
| B2 收益率不进旭日 | ❌ 丢失"结构 × 收益"的洞察 | ✗ |
| **B3 弧长=市值,颜色=收益率热力** | ✅ 保留旭日结构(市值分角)+ 诚实表达比率(绿高→赭负)· 一眼"又大又赚/又大又亏" | **✓** |

**两种渲染模式**(SUN_KIND):
- **amount / pnl**(可加):弧长 = 该指标(收益额取 `|值|`,正负用绿赭色);维值配色(金额)或幅度配色(收益额)。
- **ratio**(不可加):弧长 = 市值,颜色 = `rateColor`(收益率热力,±15% 饱和)。

### 决策 C · 持仓级维度(行业/地域)收益降级

承 PivotEngine 既有规则(诚实降级不假分摊):任一维度 holdingLevel → latestPnl / cumReturn 返回 null。

| 方案 | 选定 | 理由 |
|---|---|---|
| 假分摊到持仓 | ✗ | 违背铁律 |
| 静默显示 null | ✗ | 用户困惑 |
| **灰置 + 提示 + 自动回退累计收益额** | **✓** | `sunMetricUnavailable()` 用 `dims.holdingLevel`(已在 meta);`refresh()` 里若当前指标不可用自动回退 cumPnl(持有口径仍可) |

### 决策 D · 中心圆点击

用户明确:点中心圆 = 想换指标。选 **弹指标菜单浮层**(明确可选,vs 盲切下一个)。中心圆 `#sunCenter` 改可点(pointer-events:auto),boot() 绑定 toggle `#sunMetricPop`。

## 2 · 落地面(文件级)

- **零后端**:dims meta 已含 `holdingLevel`、measures meta 已含全部指标、PivotEngine 已算 → 无 Java/schema 改动。
- **lens.js**:
  - `SUN_METRICS`(金额/本期收益额/累计收益额/累计收益率 + kind)· `SUN_KIND` · `sunMetricUnavailable()` · `pnlColor`/`rateColor`/`mixHex` · `state.sunMetric='value'`。
  - `renderSunburst()` 重写:换 spec(rows=[内] cols=[外])· 三模式弧长/颜色/标签 · `renderSunCenter`(指标总计,hover 显块)· 引线 `renderLeaders` 传 `totalSize`(弧角基准)+ 每块 `_lbl`(指标串)。
  - `renderRanking()`:跟随指标(排序/着色/条宽)。
  - `renderSunMetricBar()` + `setSunMetric()` + `refresh()` 里自动回退 + 重绘栏 + boot() 中心圆点击。
- **lens/_section.html**:`#sunMetricBar` + `#sunDegradeNote` + `#sunCenter`(可点)+ `#sunMetricPop`。
- **style.css**:`.sun-m-off` + `#sunMetricPop button`。

## 3 · 币种不变 / 隐私 / 下钻兼容

- **币种不变**:value/pnl 随 fx 缩放、share/cumReturn 币种无关(承 PivotEngine + CurrencyInvariance 护栏)· 视图币种切换旭日跟随。
- **隐私**:金额/收益额中心与标签带 `data-priv`;收益率是比率不模糊。canvas 金额 label 走 MutationObserver 重绘(既有)。
- **下钻**:点击 drill 逻辑不变(仍两级);指标与维度正交,下钻后保持当前指标。
